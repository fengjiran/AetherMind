模块按头文件/实现文件一一对应的方式组织在 `include/aethermind/base/` 与 `src/base/` 下，形成清晰的内层公共库边界：
- 基础原语层：`macros.h`（跨编译器属性宏、`DEFINE_OBJECT_NULLTYPE`、`AM_UNREACHABLE` 等）、`check.h`（`AM_CHECK` 断言）、`alignment.h`、`env.h`。
- 错误处理层：`status.h/.cpp` 定义 `StatusCode`、`Status`、`StatusOr<T>`，通过 `static_assert` 与 C ABI `am_status_code` 保持 1:1 对齐，作为上层所有 API 的统一返回契约。
- 对象所有权层：`object.h/.cpp` 实现基于 intrusive 引用计数的 `Object` 基类及 `ObjectPtr`/`WeakObjectPtr` 智能指针，使用每类型单例 `EmptyObjectSentinel` 表示空句柄，而非 raw `nullptr`。
- 内存与存储层：`tensor.h/.cpp`（带 Buffer 的稠密张量 + `byte_offset` 偏移视图）、`tensor_view.h/.cpp`（非拥有视图）、`buffer.h`（由外部 `memory/buffer.h` 提供，被本模块引用）。
- 形状与标量层：`shape_and_stride.h/.cpp`（rank-0 特化语义）、`scalar.h/.cpp`、`mmap_file.h/.cpp`。
- 设备与调度层：`device.h/.cpp`（CPU/CUDA/CANN 三态枚举与不可变 `Device` 值类型，`Make`/`FromString` 工厂返回 `StatusOr`）、`kernel_selector.h/.cpp`、`kernel_attrs.h/.cpp`。
- 工具层：`workspace_types.h`、`workspace_arena.h`、`kv_cache_binding.h`、`traceback.h`。
依赖方向自底向上：status → object → tensor/device/kernel_*；不反向依赖上层算子或后端实现，仅通过 `c_api.h` 暴露 C ABI 状态码。
