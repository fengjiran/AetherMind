tests/unit/ 是 AetherMind 所有被测模块的一一镜像：每个子目录对应一个被测试的 aethermind 子树（base/numeric → base_and_numeric, amstring → amstring, memory → memory, backend → backend, graph → graph, shape_inference → shape_inference, operators → operators, execution → execution, kv_cache → kv_cache, model → model, compiler → compiler, runtime → runtime, inference → inference, c_api → c_api）。共享基础设施集中在 test_utils/，为上层各层提供 TensorFactory、随机张量生成、CPU 分配器桩、资源记录分配器、设备/线程基测以及断言宏；跨子系统的 C ABI 契约由 c_api/ 通过静态布局断言统一约束。顶层 CMakeLists.txt 将各子目录注册为独立 gtest binary，由 CTest 统一收集报告。Python 脚本（inference/、compiler/optimization/ 等）作为辅助 fixture 生成或数值校验步骤，由 C++ 用例驱动调用。
