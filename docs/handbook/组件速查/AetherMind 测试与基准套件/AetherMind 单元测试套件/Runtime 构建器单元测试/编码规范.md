- 每个测试通过构造 `RuntimeOptions` 并用 `builder.WithOptions(options)` 传入，再调用 `builder.TryBuild()` 获取 `StatusOr<Runtime>` 进行断言。
- 需要观测资源的测试定义自定义 `AllocatorProvider`/`BackendFactory` 派生类，通过共享的 observation 结构体记录创建/销毁次数，并在失败分支中用 `EXPECT_EQ(..., 0U)` 确认零开销。
- 对无效参数的断言统一检查 `status().code() == StatusCode::kInvalidArgument` 或 `kUnimplemented`，并通过 `status().message().find("field_name")` 定位具体字段。
- 预算与几何校验的顺序通过分别设置 `max_bytes` 过小、`head_dim=0`、`alignment=3`、`num_layers=max` 等组合用例来验证不同错误码（`kResourceExhausted`、`kInvalidArgument`、`kOverflow`）。
