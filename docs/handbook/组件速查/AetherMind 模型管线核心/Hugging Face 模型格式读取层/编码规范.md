- 对外构造失败的 API 统一返回 `StatusOr<T>` 而非抛出异常，调用方用 `AM_NODISCARD` 标注关键方法。
- HF 配置字段命名与 `config.json` key 保持 1:1 映射，并通过 `NOLINTBEGIN(readability-identifier-naming)` 豁免命名规范。
- 对敏感字符串（rope_type、dtype 等）使用固定大小 enum（底层 `uint8_t`）配合 `Parse*`/`ToString` 双向转换，保证内存紧凑与序列化稳定。
- I/O 对象采用工厂/私有构造模式（`Open`/`Load` 静态方法 + `explicit` 构造函数），并声明 Rule of 0 以表达不可变语义。
- 路径与 symlink 安全检查在读取前集中完成，通过 `RejectExistingPathIfSymlink` 拒绝链接目标，确保后续检查遵循一致策略。
