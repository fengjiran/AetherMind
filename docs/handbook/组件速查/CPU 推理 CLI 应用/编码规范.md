- CLI 选项以 `FlagSpec` 元数据表驱动，支持必需/可选标记与重复检测，未知或重复 flag 返回 `Status::InvalidArgument`。
- 数值解析使用 `ParseUnsigned<T>` 配合 `std::from_chars`，拒绝空串、非十进制字符及溢出，并以 flag 名拼接错误消息。
- 长流程错误通过 `RunStage` 枚举 + 可选 `failure_stage` 指针定位失败阶段，并由 `ReportStatus` 统一格式化输出到 stderr。
- `RunInference` 将异常边界收敛为 `Status`：捕获 `std::bad_alloc` 并转为 `StatusCode::kResourceExhausted`，其他异常向进程入口传播。
