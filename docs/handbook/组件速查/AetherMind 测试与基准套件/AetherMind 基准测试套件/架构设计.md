模块通过 `tests/benchmark/CMakeLists.txt` 构建两个独立可执行目标：
- `aethermind_benchmark`：递归收集 `tests/benchmark/*.cpp`（排除 `models/`）编译，链接 `${PROJECT_NAME}` 与 `benchmark::benchmark_main`。
- `aethermind_model_benchmark`：仅包含 `models/model_benchmark.cpp`，单独构建并依赖 spdlog；非 Linux 平台跳过该目标创建。

新增的 KV16 与投影融合基准位于 `cpu_kernels/` 下三个文件：`benchmark_cpu_kv16_execution.cpp` 通过 `ExecutionPlanBuilder` + `Runtime` 构建含 KVCacheStateBinding 的 LoweredGraph，覆盖 KV16 Attention/KVUpdate 端到端执行路径；`benchmark_cpu_kv16_kernels.cpp` 直接构造 `KVCacheLayerStorageBinding` 调用底层 attention/kvcache_update 标量参考 kernel，作为未来 SIMD 优化的正确性基线；`benchmark_cpu_projection_fusion.cpp` 使用 `CpuBackend.PrepareKernel` + `PackWeights` 对 Q/K/V 三头或双头投影进行 A32/W16 融合基准。

模型基准新增 `--kv-dtype` / `--activation-dtype` CLI 选项（限制 f32/f16/bf16），当 kv/activation dtype 为半精度时强制要求权重策略 `keep-fp16`/`keep-bf16` 且两者匹配；输出 JSON schema_version 升级为 2，并在结果中记录 prefill/decode activation bytes。报告验证由 `tools/verify_model_benchmark.py` 完成，CLI 正确性由 `tests/unit/inference/test_model_benchmark_cli.py` 校验。
