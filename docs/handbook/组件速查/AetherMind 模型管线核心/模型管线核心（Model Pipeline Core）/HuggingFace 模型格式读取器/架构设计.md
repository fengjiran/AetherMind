模块按职责拆分为五个层次，依赖方向自底向上：
- I/O 抽象层：`hf_safetensors_file.h/.cpp` 提供零拷贝 mmap 的 `HfSafetensorsFile`，每个 entry 通过绝对字节偏移共享底层 `RawStorage`；`hf_safetensors_index.h/.cpp` 解析 `model.safetensors.index.json`，给出 tensor→分片文件名映射。
- JSON 解析层：`hf_json_reader.h/.cpp` 实现 `HfJsonReader`，基于 `string_view` 的顺序游标解析标量、数组与任意值跳过，带 `kMaxSkipDepth=32` 防御性深度限制；上层 `hf_directory_reader.cpp`、`hf_safetensors_index.cpp` 直接继承复用。
- 配置层：`hf_model_config.h/.cpp` 定义 `HfModelConfig`/`HfRopeConfig`/`HfRoPEAlgorithm`，字段名与 HF config.json 一一对应，未知字段被忽略以兼容上游演进。
- 目录编排层：`hf_directory_reader.h/.cpp` 通过 `InspectDirectory` 检测单文件或分片布局（`HfDirectoryLayout`），暴露 `ParseConfig()` 与 `LoadRawWeightTable()` 两个入口。
- 名称解析与校验层：`hf_tensor_resolver.h/.cpp` 把 HF 命名规范（如 tied embedding alias）映射为 `ResolvedModelWeights`；`hf_model_validator.h/.cpp` 提供三阶段静态校验：`ValidateConfig` → `ValidateWeightSet` → `ValidateResolvedModel`，策略由 `ModelValidationOptions` 控制。
- 工具层：`hf_utils.h` 提供 dtype 字符串到 `DataType` 转换、路径消息格式化与 symlink 拒绝等公共辅助。
所有公开 API 返回 `StatusOr<T>` 而非抛出异常；类构造通过私有构造函数 + static factory 模式完成错误处理。
