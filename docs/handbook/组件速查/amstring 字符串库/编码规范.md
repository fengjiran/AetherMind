- 所有对外接口在 BasicString 层转发到 BasicStringCore，Core 层再委托给 LayoutPolicy/GrowthPolicy，避免跨层直接调用。
- 策略通过 C++ Concepts（`AmStringLayoutPolicy`、`AmStringDecodedLayoutPolicy`）在编译期校验，而非运行时判断或文档约定。
- 常量配置集中在 `aethermind::config` 命名空间（如 `kGrowthFactorDenominator`、`kLargeThresholdBytes`），策略与 Core 均通过该命名空间引用。
- 分配器行为通过 `AllocatorTraitsHelper` 的条件分支处理 `propagate_on_*_assignment` 与 `is_always_equal`，Copy/Move 赋值各自分支复用同一模式。
- 所有公共类型均在 `aethermind` 命名空间下组织，并以 `AM_NODISCARD` 宏标注返回 size/capacity 等无副作用查询函数。
