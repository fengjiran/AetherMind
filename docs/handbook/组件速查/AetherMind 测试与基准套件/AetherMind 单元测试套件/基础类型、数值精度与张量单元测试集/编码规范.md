- 每个被测类或功能域对应一个独立的 `test_*.cpp` 源文件，文件名与被测头文件同名且位于镜像的 `base/`、`numeric/`、`tensor/` 子目录下。
- 测试用例统一放在匿名命名空间中，并通过 `using namespace aethermind;`（必要时追加 `using namespace aethermind::detail;` 或 `test_utils`）引入符号。
- 对需要访问内部实现细节的测试，通过在测试文件顶部重新声明对应 `aethermind::detail` 命名空间内的辅助函数以绕过封装。
- 随机张量输入通过共享的 `test_utils/tensor_random.h` 中 `RandomUniformTensor` 生成器构造，而不是在测试内手写数据。
- 数值边界与期望值采用字面常量（如十六进制位模式、`std::numeric_limits` 极值）直接写入 `EXPECT_EQ` / `EXPECT_TRUE` 断言，保持可追溯性。
