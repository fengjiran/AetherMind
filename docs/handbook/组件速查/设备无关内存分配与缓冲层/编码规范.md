- `MemoryHandle` 采用移动语义且删除拷贝，借出内存通过 null deleter 或 `NoOpMemoryDeleter` 表达，拥有内存则必须提供非空的 `memory_deleter_fn`。
- `BufferImpl` 构造时对 nbytes、device、alignment 执行 `AM_CHECK` 断言，违反不变式直接 abort 而非返回错误。
- `Allocator::TryAllocate` 作为唯一对外入口，把底层 `AllocateStorage` 的所有失败（含 `std::bad_alloc`）都规约为 `Status`，OOM 统一映射为 `ResourceExhausted`。
- 具体后端通过继承 `Allocator` 并实现 `AllocateStorage` + `device()`，同时由独立的 `*AllocatorProvider` 子类实现 `CreateAllocator` 交由 `AllocatorRegistry` 管理。
- 运行时状态如 `AllocatorRegistry` 内部未加锁，注释明确标注需调用方串行化并发访问。
