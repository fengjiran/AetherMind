- 每个算子在 `aethermind::cpu::detail` 下以 `Build*F32ReferenceArgs(KernelParamsBuildContext&, void*)` 作为唯一参数构建入口，并使用 placement-new 将构造好的 `*F32KernelArgs` 写入 `params_buffer`。
- 张量有效性、dtype 与 rank 校验统一通过返回 `Status::InvalidArgument` 的错误消息完成，错误消息中嵌入算子名以便定位。
- 行主布局分析走 `ComputeFlattenedRowCount` + `AnalyzeRowwiseView` + `ValidateRowwiseOutputLayout` 三段式，随后用 `ValidateRowwiseDisjoint` 确保输入/输出与 packed weight 之间无内存重叠。
- 带 split 的算子（QKV、Gate-Up）先通过 `ReadMetadata(attrs)` 解析 `*F32KernelMetadata`，再用独立的 `TotalOutFeatures` 辅助函数做非负性与 `CheckOverflowAdd` 溢出检查。
- 空张量早退：当 `row_count == 0` 或对应 out_features 为 0 时直接构造零参数字面量并返回 `Status::Ok()`，避免进入计算循环。
- 可优化的路径通过 `#if defined(GEMM_HAS_AVX2_FMA_KERNEL)` 包裹，同时保留标量 Reference 实现作为默认回退。
