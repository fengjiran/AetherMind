- 对外 API 的错误路径统一返回 `Status` 或 `StatusOr<T>`，构造函数抛异常时使用 `AM_CHECK`，工厂方法如 `Device::Make`、`Device::FromString` 则返回 `StatusOr`。
- 枚举值与 C ABI 对齐时同时声明 `static_assert` 映射表（见 `status.h` 中 `StatusCode` 与 `am_status_code`），新增枚举项需同步更新两端。
- 可空句柄采用每类型单例哨兵（`EmptyObjectSentinel<T>::singleton()`）而非 raw `nullptr`，并通过 `defined()`/`get_or_null()`/`IsEmptyObjectSentinel` 观察空状态。
- 对编译器和 sanitizer 差异通过 `AM_HAS_BUILTIN`/`AM_HAS_CPP_ATTRIBUTE`/`AM_SANITIZE_ADDRESS` 等宏进行条件封装，调用方直接使用 `AM_NODISCARD`、`AM_UNLIKELY`、`AM_UNREACHABLE` 等统一接口。
- 头文件内联函数普遍标注 `noexcept`，并配合 `AM_NODISCARD` 提示调用方检查返回值，避免静默忽略错误状态。
