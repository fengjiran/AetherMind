- 每个内核目录采用 `*_internal.h` 声明 POD 参数结构与 `Run*Reference` 微内核、`*_entry.cpp` 实现 params builder 与 kernel entry 的两文件拆分模式。
- 参数构建函数统一命名为 `Build*F32ReferenceArgs(const KernelParamsBuildContext&, void* params_buffer)`，使用 placement new 构造 POD 参数对象返回给运行期。
- 所有输入张量校验均返回 `Status::InvalidArgument`，并使用 `AM_ASSIGN_OR_RETURN` / `AM_DCHECK` / `CheckOverflowMul` 等宏处理溢出与断言。
- attrs 中以二进制 POD 布局传递只读元数据（如 axis、RoPE metadata + frequency tables），由 binding-time 完成布局验证，执行期不再读取 OpParams。
- 对空张量的快速路径通过设置零 numel 并允许指针为空来跳过实际计算，仅在非空分支才进行数据指针与内存重叠检查。
