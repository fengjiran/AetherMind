模块以 `include/c_api.h` 为唯一对外头文件，通过 `extern "C"` 暴露零拷贝句柄（`am_runtime_t` / `am_model_t` / `am_session_t` / `am_error_handle`）和固定布局结构体（`am_config_t`、`am_session_config_t`），并以 `AM_ABI_VERSION_MAJOR/MINOR` 进行 ABI 版本锁定。
- `src/c_api_runtime.cpp`：实现 Runtime/Model/Session 的创建、加载与同步推理；内部用 `RuntimeState`、`ModelState` 等 struct 封装底层 `aethermind::Runtime`、`ExecutableModel`、`InferenceSession`，并通过 `CopyConfig` + `ToSize` 校验 `struct_size`、ABI 版本与几何参数后再构造上层对象。
- `src/c_api_error.cpp`：实现 `am_error_create/destroy/code/message`，以 `AMErrorObject` 持有 `am_status_code` 与 `std::string` 消息，作为 C 边界上的可分配诊断对象。
- `src/any.cpp`：实现 `aethermind::Any`，基于 `std::variant<std::monostate, SmallObject, std::unique_ptr<HolderBase>>` 支持小对象内联与大对象堆分配两种存储路径，提供 `GetHolderPtr` / `GetDataPtr` / `type()` / `EqualsTo` 等访问接口。
- `src/format.cpp`：在 `aethermind` 命名空间下实现 Tensor 的 `std::format` 风格打印，自动选择 Default/Scientific/Fixed 格式并按数据范围计算缩放。
依赖方向单向向外：C API 层调用 `aethermind/inference`、`aethermind/model`、`aethermind/runtime` 等内部库，不反向被它们引用；`c_api_runtime_internal.h` 仅作为内部桥接头。
