- 每个被测单元以独立的 `benchmark_*.cpp` 文件组织，按功能域分目录（amstring、cpu_kernels、models），便于 CMake 递归收集或单独隔离。
- 模型测量与通用 micro-benchmark 分离为两个独立可执行目标，分别链接不同的依赖集（benchmark_main vs spdlog）。
- CPU kernel 基准统一通过 `KernelSelector{device_type=kCPU, act_dtype=Float32(), ...}` 选择后端，再经 `backend.PrepareKernel` / `PackWeights` 准备参数与打包权重后在循环内仅调用 `kernel.fn`。
- 基准函数使用 `std::array<std::byte, kMaxKernelParamsSize>` 对齐存储 `kernel_params`，并将准备阶段与计时循环分离（preparation outside the loop）。
- 构建期元数据通过 CMake `file(GENERATE ...)` 生成私有头文件并由编译器强制 include，而非通过 `-D` 宏传递含引号/反斜杠的复杂标志串。
