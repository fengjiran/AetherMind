测试文件按被测 API 分层组织：
- 计划与构建器：`test_execution_plan*.cpp`、`test_execution_plan_builder.cpp` 直接构造 `ExecutionPlan` / `ExecutionPlanBuilder`，通过自定义 `KernelParamsBuildContext` 回调注入参数构建逻辑。
- 绑定层集成：`test_execution_bindings.cpp`、`test_runtime_backend_integration.cpp` 从图/算子（如 `embedding_op`）经 `RuntimeBuilder` 落到执行层，验证端到端绑定行为。
- 执行器与后端路径：`test_executor_backend_path.cpp` 实现自定义 `Backend` 派生类 `ExecutorTestBackend`，驱动 CPU workspace arena 并校验 kernel 调度。
- KV Cache 专用：`test_kvcache_update_kernel.cpp` 借助 `kv_cache/test_kv_cache_helpers.h` 构造 KV 读/写 binding 并断言内核接收到的上下文。
- 共享辅助头：`test_execution_binding_helpers.h` 与 `test_tensor_buffer_helpers.h` 提供跨用例复用的 Fake Kernel、对齐缓冲区等桩实现。
所有用例均基于 gtest，依赖 `aethermind/backend/*`、`memory/cpu_allocator.h`、`model/weight/*` 等被测模块的头文件，不引入运行时二进制依赖。
