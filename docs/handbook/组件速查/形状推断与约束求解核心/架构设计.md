模块以三层自底向上组织：
- 基础类型层（shape_symbol.h/tensor_spec.h）：ShapeSymbol 用负整数表示未解析的符号维度、非负整数表示静态维度、-1 表示 Unknown；SymbolicShape 封装可选 rank 与 ShapeSymbol 向量，并提供 Join（控制流合并）与 Unify（算子输入对齐）两种语义；TensorSpec 将 DataType 与 SymbolicShape 配对作为 plan-time 契约。
- 约束表达层（shape_constraint.h）：通过 std::variant 统一 DimEqual / DimBroadcastable / VolumeEqual / RankEqual / RankAtLeast / DimPositive 等结构体，并由 ShapeConstraint 携带诊断字符串视图；EvaluationResult 三态返回满足/违反/推迟。
- 求解与评估层：broadcast.cpp 提供 Concrete 与 Symbolic 两套广播计算接口（InferBroadcastShape 产出 DeferredBroadcastAxis 供后续消解）；symbol_constraint_solver.h/.cpp 在计划期使用并查集维护 ShapeSymbol 等价类与静态绑定；shape_constraint_evaluator.cpp 提供 EvaluateShapeConstraint 的双入口——对 SymbolicShape 可能返回 kDeferred，对 TensorView 则只做运行时校验；ValidateTensorBindingPremises 在绑定阶段重放 plan-time 已证明的约束前提，确保 dtype/rank/静态维/符号身份一致。
依赖方向单向向下：evaluator/solver/broadcast 依赖 shape_symbol 与 shape_constraint，对外仅暴露头文件接口。
