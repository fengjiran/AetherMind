- 每个算子实现一个 `InferXxx(const OpParams&, std::span<const TensorSpec>) -> StatusOr<InferenceResult>` 函数，并在 `aethermind::detail` 命名空间内定义。
- 参数校验优先于输入校验：先用 `std::holds_alternative<XxxParams>` 确认参数类型，再用 `ValidateInferenceInputCount(OpType::kXxx, inputs)` 固定输入数量。
- dtype 校验成对使用 `IsXxxSupportedDType` 与 `MakeXxxUnsupportedDTypeMessage` 生成错误消息，避免手写字符串。
- 形状规则按职责拆分到 `ValidateXxxParams` / `ValidateXxxDTypes` / `ValidateXxxShapes` 等局部辅助函数，主推断函数仅串联调用并收集 `runtime_checks`。
- 无法在编译期判定的形状关系通过向 `InferenceResult::runtime_checks` 追加 `DimBroadcastableConstraint` / `DimPositiveConstraint` / `DimEqualConstraint` 表达，而非直接报错。
- 对可能溢出的整型乘法使用 `CheckOverflowMul` 或显式 int64_t 转换后再比较，确保静态 shape 计算安全。
