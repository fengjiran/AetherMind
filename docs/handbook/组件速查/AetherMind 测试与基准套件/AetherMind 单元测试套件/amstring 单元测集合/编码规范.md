- 针对每种 LayoutPolicy 创建独立的 `*_layout_policy.cpp` 测试文件，并以类名命名 TEST 组。
- 多字符类型的通用断言统一通过 `TYPED_TEST` + `AmstringCharTypes = ::testing::Types<char, char8_t, char16_t, char32_t, wchar_t>` 参数化。
- 验证布局常量时使用 `static_assert` 检查 `sizeof(Policy::Storage) == sizeof(Policy::ExternalRep)`、`kStorageBytes`、`kSmallCapacity` 等常量，以对齐内存布局约定。
- 构造状态感知分配器时复用 `StatefulAllocator<T>` 模板，包装 `std::allocator` 并维护 `id` 用于区分实例。
- 对内部存储的探测字节/探针字写入采用辅助函数（如 `WriteProbeByte`/`WriteProbe`），通过 `kProbeByteOffset` 偏移访问 `storage.raw`。
