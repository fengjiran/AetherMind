- 每个算子目录采用 `*_internal.h` + `*_entry.cpp` + `*_reference.cpp` 的三段式划分：头文件只暴露 POD `*KernelArgs` 与 `RunXxxReference` 接口，入口文件负责参数构建与 `AM_REGISTER_KERNEL` 注册，实现文件专注数值计算。
- 参数构建函数签名统一为 `Status BuildXxxArgs(const KernelParamsBuildContext& context, void* params_buffer) noexcept`，在缓冲区内以 `::new (params_buffer) XxxKernelArgs(args)` 进行 placement new，并配合 `static_assert(std::is_trivially_destructible_v<XxxKernelArgs>)` 保证内存安全。
- Tensor 合法性校验集中在参数构建阶段：检查 inputs/outputs 数量、dtype 一致性、rank/shape 匹配、非空数据指针，并使用 `AM_ASSIGN_OR_RETURN` / `AM_RETURN_IF_ERROR` 传播 `StatusOr` 错误。
- 别名与布局验证统一通过 common 工具完成：add/silu 使用 broadcast_utils 的 `ValidateAndBuildBroadcastArgs`、`CheckedOutputNumel`、`BuildStridedAddressFootprint`，rmsnorm 使用 layout_utils 的 `AnalyzeRowwiseView`、`ComputeFlattenedRowCount`、`ValidateRowwiseDisjoint`。
- `AM_REGISTER_KERNEL` 注册块固定包含 `device_type=kCPU`、`weight_format=kPlain`、`phase=ExecPhase::kBoth`、`priority=10`，并按 dtype 分别声明 `act_dtype`/`weight_dtype`，name 字段遵循 `cpu::<op>_<dtype>_<backend>` 命名约定。
- 对于可原地执行的算子（silu、rmsnorm），先尝试 `HaveIdenticalViewMapping(input, output)` 判定精确 in-place，否则再对 input/output 或 output/weight 的 footprint 执行互斥校验，以保证读早于写的语义。
