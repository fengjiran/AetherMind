模块按职责拆分为三个子目录：
- `tests/unit/test_utils/`：纯头文件 + 一个 GTest Listener（`test_required_execution_guard.cpp`），提供 `aethermind::test_utils` 命名空间下的张量工厂（`tensor_factory.h`，基于 `posix_memalign` 创建对齐 Buffer）、随机填充（`tensor_random.h`，封装 `std::mt19937_64` 的 uniform/normal/int 分布）和浮点/位级断言（`tensor_assert.h`，返回 `AssertionResult` 并限制最大报告条目数）。同时暴露 `aethermind::test` 命名空间下的进程级 CPU 分配器单例（`test_allocator.h`）与可注入 `fail_on_call` 的资源记录分配器及 Provider（`test_resource_allocator.h`），用于观测底层 `Allocator` 调用序列。
- `tests/unit/device/`：针对 `aethermind/base/device.h` 与 `std::thread`/`std::jthread` 的 GTest 用例，覆盖 DeviceType/Kind/字符串解析/Make 校验等。
- `tests/unit/cmake/`：通过 `unittest.TestCase` 动态加载 `tools/verify_cpu_isa_build.py`，构造假的 `compile_commands.json` 以断言 AVX2 可选实现与基准翻译单元的隔离契约。
依赖方向单向指向被测核心库（`aethermind/base`、`aethermind/memory`、`container`、`utils`），不反向被生产代码引用。
