- 对外 API 统一返回 `StatusOr<T>`，错误分类使用 `InvalidArgument`、`ResourceExhausted`、`Overflow` 等语义化状态码。
- 所有权与可见字节统计采用 owner-aware 去重策略：共享 `Buffer` 归属同一份 backing，重复 view 不计入多次。
- 可选容量上限（如 `max_payload_bytes`、`max_owned_weight_bytes`）通过 `std::optional<size_t>` 或显式 Options 结构体传入，零值表示不限流。
- 关键标识由多字段组合构成（如 `WeightArtifactKey` 包含 source_id/value_index/binding/selector/recipe），避免单一维度碰撞。
