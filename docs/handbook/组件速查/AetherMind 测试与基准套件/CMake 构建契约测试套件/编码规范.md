- 契约脚本统一以 `cmake_minimum_required(VERSION 3.28)` 开头，并通过检查必要变量是否为空或绝对路径来报告用法错误。
- 对外部命令失败的处理采用 `execute_process` + `run_contract_command` 模式，将 stdout/stderr 写入 `<case>.log` 并以 `message(FATAL_ERROR ...)` 终止，同时支持 `expected_success` 布尔反转以断言预期失败。
- 每个被测试的 CMake 功能都封装为独立的 `*_project/` 子目录，由顶层 `test_*.cmake` 通过 `-S <dir> -B <dir>` 触发全新配置，避免跨 case 的缓存污染。
- Python 契约通过设置 `CMAKE_DISABLE_FIND_PACKAGE_Python3 ON` 与预置 `AETHERMIND_PYTHON_FOUND`/`AETHERMIND_PYTHON_SOURCE` 来模拟已发现结果，再验证 `aethermind_find_python` 是否尊重禁用标志。
- 测试标签断言通过 `expect_label(test name label expected)` 辅助函数完成，集中声明每个测试应拥有或不拥有的标签集合。
