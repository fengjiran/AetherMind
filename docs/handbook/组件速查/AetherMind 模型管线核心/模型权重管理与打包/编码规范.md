- 对外头文件统一使用 `/// @file` + `/// @brief` Doxygen 注释描述文件职责，并在命名空间末尾闭合 `#endif`。
- 错误路径通过 `Status` / `StatusOr<T>` 返回，而非异常；构造函数与查询函数普遍标注 `noexcept` 以避免异常开销。
- 所有权通过 `std::shared_ptr<const PackedWeight>` 共享给 ExecutionPlan，使 plan 可在 collection 销毁后继续执行。
- 权重身份采用多字段结构体（如 `WeightArtifactKey`、`WeightPackingRequest`）而非单一 key，由 `operator==` 默认生成以保证五元组唯一性。
- 资源上限通过显式 Options 结构体（`ModelWeightNormalizationOptions`）传入，零值表示无限制，并由 Usage 结构体输出观测指标。
