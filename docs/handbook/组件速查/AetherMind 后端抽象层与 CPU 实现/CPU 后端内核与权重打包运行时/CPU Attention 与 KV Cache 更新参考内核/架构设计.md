模块按算子职责划分为两个并列子目录，结构对称：
- `attention/`：通过 `attention_internal.h` 定义 `AttentionF32KernelMetadata`（冻结的 head 几何）与 `AttentionF32KernelArgs`（查询/输出视图、步长），由 `attention_entry.cpp` 中的 `BuildAttentionF32ReferenceArgs` 将 `KernelParamsBuildContext` 解析并构造该参数结构体；运行时再经 `KVCacheReadBinding` 读取 key/value 缓存，调用 `RunAttentionF32Reference` 执行因果缩放点积注意力。
- `kvcache_update/`：通过 `kvcache_update_internal.h` 定义 `KVCacheUpdateF32KernelArgs`（key/value 激活视图），由 `kvcache_update_entry.cpp` 解析上下文后调用 `RunKVCacheUpdateF32Reference`，借助 `KVCacheAppendBinding` 将窗口 `[begin, end)` 写入缓存。

两子目录均不直接持有缓存指针——缓存存储与可见范围由 `KernelContext::kv_read` / `kv_append` 注入，使内核仅处理“冷路径”激活数据。布局正确性统一通过 `aethermind/backend/cpu/kernels/common/alias_utils.h` 提供的 `BuildStridedAddressFootprint`、`ValidateLayoutInjectivity`、`ValidateStridedDisjoint`、`ByteRangesOverlap` 等工具完成 alias 分析，并以 `Status::InvalidArgument` 报告越界或重叠。所有内核以 `aethermind::cpu::detail` 命名空间暴露 `Run*F32Reference` 入口，供上层调度器在 CPU 路径选择时调用。
