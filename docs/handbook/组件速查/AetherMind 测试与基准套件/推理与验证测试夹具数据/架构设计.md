本模块仅包含三组独立的只读夹具目录，每组由 README.md + 元数据文件组成，不含有可执行代码：
- `inference_admission/`：FP32 HF 源模型的 `recipe.json` 与 `checksums.json`，用于生成 20 种 F16/BF16/tied 等变体并通过 `ModelLoader::Load` 准入。
- `inference_numerical/`：在 admission 之上扩展的独立数值黄金集，包含多几何（mha/gqa/mqa/untied/tied/near-limit）的 `reference.safetensors`、`reference.json`、`manifest.json` 以及 `requirements-reference.txt`，由 `tools/generate_llama_numerical_reference.py` 产出并由 `tools/verify_llama_numerical_reference.py` 严格校验。
- `final_validation/`：冻结的最终集成矩阵策略 `policy.json`，通过 SHA256 指纹锁定每个 CTest slice 的完整用例集合。
依赖方向单向向外：C++ 单元测试与 Python 工具读取这些 JSON/safetensors 作为输入，但本目录不被构建系统编译，也不被运行时加载。
