测试按被测源码目录镜像组织为三个子树：`tests/unit/base/` 覆盖标量、数据类型、内存映射、溢出检查、哈希等基础基础设施；`tests/unit/numeric/` 覆盖 `aethermind/dtypes/` 下的 Half、BFloat16、Float8 E4M3FN/E5M2 及内置 map；`tests/unit/tensor/` 覆盖 `aethermind/tensor/` 下的 Shape/Stride、String、TensorRandom、TensorView 等。所有用例通过 `<gtest/gtest.h>` 以 `TEST(TestCase, Name)` 宏编写，使用 `EXPECT_*` / `ASSERT_*` 断言；对需访问内部实现 API 的场景（如 half 的位级转换函数），通过在测试文件内重新声明 `aethermind::detail` 命名空间中的辅助函数来绕过封装。测试共享数据通过 `../test_utils/tensor_random.h` 提供的 `RandomUniformTensor` 生成器复用，避免在单个测试文件中重复构造随机张量的样板代码。
