- Pass 类测试通过派生 `GraphPass` 并重写 `Name()` 与 `Run(GraphRewriteSession&, PassContext const&)` 来构造被测场景。
- 测试用例统一以 `TEST(<Fixture>, <Case>)` 宏命名，并在 `namespace { ... }` 匿名命名空间内声明测试类或局部变量。
- 复用图结构时，将共享的图构建函数（如 `BuildTwoEmbeddingGraph`）提取到 `optimization/test_optimization_helpers.h`，供多个 Pass 测试共用。
- 对可能失败的 API 调用（如 `AddNode`、`AddLinear`）统一使用 `ASSERT_TRUE(...ok()) << status().ToString()` 进行断言后再解引用返回值。
