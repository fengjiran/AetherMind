模块按功能划分为多个独立头文件，全部暴露于 `aethermind` 或 `aethermind::utils` 命名空间下，无运行时链接依赖，主要由顶层其他子系统直接 include。

- 数值安全 (`overflow_check.h`, `numeric_utils.h`)：在 `aethermind` 命名空间内通过 `__builtin_*_overflow` 与可移植回退实现提供 `CheckOverflowAdd/Mul/Sub`、`CheckNarrow`、`SafeMultiplyU64`，并定义 `CheckNarrowInteger` / `OverflowInteger` 概念限制类型范围；`IsFinitePositive` 是极简谓词。
- 哈希系统 (`hash.h`)：自定义 `aethermind::hash<T>` 模板优先走用户特化的 `T::hash`，其次枚举底层值，最后回退 `std::hash`；内置对 `int/uint32_t/int64_t/long long`、`pair`、`tuple`、`vector` 的特化，并提供 `get_hash(...)` 组合键工具与 twang 混合函数。
- 浮点解析 (`parse_number.h` + `src/utils/parse_number.cpp` + `parse_number_internal.h`)：仅 `ParseFloat` / `ParseDouble` 两个 `noexcept` API，Apple 上回退到 `strtod_l`/`strtof_l("C" locale)`，其余走 `std::from_chars`，保证完整消费语义与平台无关行为。
- 断言与日志 (`logging.h`)：`AM_CHECK` / `AM_DCHECK` 宏配合 `HandleCheckFailed` 输出稳定前缀 `Check failed: ...`，供 death test 匹配；`NDEBUG` 下 `AM_DCHECK` 展开为空语句。
- 语言辅助 (`variant_utils.h`)：`overloaded` 结构体与推导帮助，用于把多个 callable 合并成 `std::visit` 调用者。
- 领域工具 (`qualified_name.h`)：不可变的点分限定名类，缓存全名、前缀与末段，并在 `std` 命名空间扩展 `hash` 特化。

依赖方向单向向下：`overflow_check.h` 依赖 `logging.h`（用于 `AM_DCHECK`），其余工具之间互不耦合，均依赖上层容器/字符串抽象（如 `container/array_view.h`、`container/string.h`）。
