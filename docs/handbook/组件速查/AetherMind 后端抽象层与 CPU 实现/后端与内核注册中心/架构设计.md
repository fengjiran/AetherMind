模块分为三层：
- 抽象层（include/aethermind/backend/*.h）：`Backend` 抽象接口定义 `PrepareKernel`/`PackWeights` 等能力；`BackendFactory` 通过 `Create()` 返回具体后端实例；`BackendRegistry` 维护 `DeviceType → BackendFactory` 映射并以 `unordered_map` 缓存已创建的 `Backend`，`GetBackend` 懒加载。
- 注册层（kernel_registry.h / kernel_static_registration.h）：`KernelRegistry` 是单例，通过 `AM_REGISTER_KERNEL` 宏在编译期由每个 kernel 目标文件触发静态构造完成注册，使用 `RegistrationKey`(OpType + KernelSelector + CpuFeatureSet) 去重并按 OpType 建桶索引；`Freeze()` 后禁止再注册。
- CPU 实现层（src/backend/cpu/*）：`CpuBackend` 持有 `CpuCapabilities` 快照，将 `KernelRegistry` 中按 selector 匹配的候选进一步按 `effective_features` 与优先级筛选并冻结为 `ResolvedKernel`；`CpuBackendFactory` 封装能力检测并通过 `Status` 通道返回错误。

依赖方向：CPU 实现 → 抽象接口 → 注册中心；外部仅通过 `BackendRegistry::GetBackend` 和 `KernelRegistry::Global` 访问，不直接感知 CPU 实现细节。
