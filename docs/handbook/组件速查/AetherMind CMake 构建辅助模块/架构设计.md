本模块由一组独立的可复用 CMake 脚本组成，均通过 `include_guard(GLOBAL)` 暴露函数式 API，供顶层 CMakeLists.txt 按需 include：
- 共享依赖管理：`AetherMindDependencySources.cmake` 提供 `aethermind_declare_shared_dependency` / `aethermind_make_shared_dependency_available` 两个函数，基于 FetchContent 声明第三方源码；`AcquireSharedDependency.cmake` 作为被 FetchContent 以 `-P` 模式调用的子进程脚本，负责在 `SOURCE_DIR` 下原子克隆、校验 tag 一致性并避免并发冲突（`file(LOCK ... GUARD PROCESS)` + 临时目录重命名）。
- CPU ISA 探测：`AetherMindCpuIsa.cmake` 使用 `check_cxx_source_compiles` 检测 AVX2/F16C/AVX2-FMA，并通过 `aethermind_configure_*_sources` 函数向源文件追加 `-mavx* -mfma -fno-lto` 编译选项与 `SKIP_UNITY_BUILD_INCLUSION`。
- 构建期检查：`AetherMindBuildChecks.cmake` 用 `try_compile` 在目标编译器侧验证 `KALLOC_ALIGNMENT` 是否为 2 的幂且可表示为 `size_t`。
- Sanitizer：`AetherMindSanitizers.cmake` 通过 CACHE STRING 选择 none/asan-ubsan/tsan，并用 C/C++ 双向 compile+link 探测工具链可用性后，经 `aethermind_apply_sanitizer(target)` 注入到项目目标。
- 外部库：`AetherMindLibbacktrace.cmake` 通过 `ExternalProject_Add` 从 `3rdparty/libbacktrace` 构建静态库并暴露 IMPORTED target。
- 测试基础设施：`AetherMindTests.cmake` 定义 `aethermind_configure_test_options` 与大量正则匹配的 `aethermind_test_labels`，按 test case 名自动标记 smoke/numerical/model/interposer/lifecycle 等标签；`AetherMindFindPython.cmake` 为其提供 Python 查找支持。
依赖方向单向向外：所有脚本仅依赖标准 CMake 模块（FetchContent、ExternalProject、CheckCXXSourceCompiles），不被彼此循环 include。
