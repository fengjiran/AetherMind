共享依赖需先通过 `aethermind_declare_shared_dependency(NAME SOURCE REPOSITORY TAG)` 声明绝对路径与版本 tag；随后调用 `aethermind_make_shared_dependency_available(NAME TARGETS ...)` 完成获取，其中 `SOURCE` 必须存在且非符号链接，否则脚本会尝试 clone 到该路径。可通过环境变量 `AETHERMIND_DEPENDENCY_LOCK_TIMEOUT`、`AETHERMIND_DEPENDENCY_DOWNLOAD_TIMEOUT` 调整锁与下载超时。
