- 所有对外 C 函数返回 `am_status_code` 或裸指针，错误通过可选的 `am_error_handle* error` 输出，函数本身不抛出异常也不让异常逃逸到 C 侧。
- 对外配置结构体统一以 `struct_size` + `abi_version` 双字段开头，由 `CopyConfig` 先校验前缀再按完整大小复制，防止短前缀越界。
- 句柄生命周期采用显式 `*_create` / `*_destroy` 配对，销毁函数对 NULL 做 no-op 且非空句柄只允许释放一次。
- `Any` 的小对象与大对象分支分别通过 `std::visit` 模板 lambda 与 switch-on-index 两套实现并行维护，由 `USE_VISITOR_PATTERN` 宏切换。
