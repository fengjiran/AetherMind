模块按职责拆分为四个头文件，实现位于同名 src/container/*.cpp：
- array_view.h：通过 `USE_SPAN_AS_ARRAY_VIEW` 宏在默认路径（`std::span<const T>`/`std::span<T>` 别名）与自定义 `ArrayView<T>` 类之间切换，提供 `make_array_view`、`to_vector`、`IntArrayView` 等辅助。
- amstring.h / amstring.cpp：`AMStringCore<Char>` 基于小字符串优化（SSO），将短字符串内联存储、中/长串用 `MediumLarge` 结构体把 data/size/capacity/category 压缩进单字，并通过 `MagicConstants` 针对大小端平台做位布局优化；同时暴露 `details::PodCopy/PodMove/PodFill` POD 零拷贝工具。
- string.h / string.cpp：`StringImpl` 继承 `Object` 保存裸指针数据，`String` 继承 `ObjectRef` 实现共享引用计数；通过 `details::IteratorAdapter` + `Converter` 将原生 char* 迭代器适配为返回 `char&` 的迭代器，支持 KMP/Boyer-Moore/Naive 三种查找策略。
- container_utils.h：纯模板工具层，提供 C++20 concept (`is_valid_iterator_v`) 与旧标准回退、无符号数转十进制字符表、`IteratorAdapter` 等可复用组件。
依赖方向单向向下：string 依赖 container_utils 和 base/object_allocator；amstring 仅依赖 base 与 any_utils；array_view 依赖 base/macros 与 utils/hash，彼此不互相包含。
