每个算子是一个独立的子目录，遵循统一的三件套结构：`*_internal.h` 定义预校验的 `*KernelArgs` POD 结构与 `RunXxxReference` 入口；`*_entry.cpp` 负责从 `KernelParamsBuildContext` 解析输入/输出/属性，调用公共工具（broadcast_utils、alias_utils、layout_utils）完成形状广播与别名冲突检测，将结果原位构造到 `params_buffer`，再通过 `AM_REGISTER_KERNEL` 以 `KernelDef` 静态注册到调度器；`*_reference.cpp`（以及 rmsnorm 下的 `rmsnorm_f32_avx2.cpp`）提供具体实现。

- add：通过 `ValidateAndBuildBroadcastArgs` 复用通用广播路径，按 dtype 分派 Float32/Double/BFloat16/Int32/Int64 五种类型，每种均使用同一 `AddEntry` 入口。
- silu：仅支持 FP32，校验 input/output 形状一致性与输出映射的可逆性（injectivity），允许精确 in-place 别名或要求互斥 footprint。
- rmsnorm：FP32 专用，分离通用模板 `ValidateAndBuildRmsNormArgs` 与 F32 shell `ValidateAndBuildF32Args`；除 reference 外还提供 `AVX2/FMA` 变体，通过 `RMSNORM_HAS_AVX2_FMA_KERNEL` 条件编译开关；同时支持 packed weight identity 路径，依赖 `PackedWeightView` 与行步长分析。

依赖方向单向向外：本模块仅依赖上层基础设施（kernel_context、kernel_types、kernel_static_registration、common/* 工具），不反向被 operators 直接 include internal 头文件。所有 `*KernelArgs` 都声明为 trivially destructible 且满足 `alignof(std::max_align_t)`，以便安全地用 placement new 驻留在共享参数缓冲区。
