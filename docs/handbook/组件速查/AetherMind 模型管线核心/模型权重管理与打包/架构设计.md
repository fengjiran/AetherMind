模块按职责划分为四个独立子单元，依赖方向自上而下为：weight_packing_request → packed_weight_collection → backend；model_weight_normalization 与 model_weight_storage_summary 作为独立的预处理与度量工具。
- weight_packing_request.h 定义 `WeightPackingRequest`，承载编译期生成的每个权重视图及其 OpType、source_id、value_index、binding、selector 与 PackingRecipe，是编译阶段与准备阶段的共享数据契约。
- packed_weight_collection.h/.cpp 实现 `PackedWeightCollection` 与 `PrepackWeightRequests`：前者以 `(source_id, value_index, binding, selector, recipe)` 五元组为键持有 `PackedWeight` 共享指针，维护 source_frozen_ 单源不变量并统计 total_storage_bytes / storage_plan_complete；后者批量调用 Backend::PackWeights，保证“全部成功或全部回滚”的原子语义。
- weight_binding_resolver.h/.cpp 暴露唯一的 `ResolveWeightBinding`，把 `WeightBinding`（含 Qkv/GateUp 复合）映射到 `ResolvedModelWeights` 中的 `RawWeightView*`，统一处理 tied lm_head 回退与缺失角色。
- model_weight_normalization.h/.cpp 通过 `NormalizeLoadedModelWeightsToFp32` 在编译前产出 FP32 宽化的 OwnedModel，配合 `ModelWeightNormalizationOptions` 与 `ModelWeightNormalizationUsage` 报告峰值内存。
- model_weight_storage_summary.h/.cpp 提供 `SummarizeModelWeightStorage`，对 ResolvedModelWeights 做去重后的 mapped/owned/external/logical_view 字节统计，不读取张量负载。
所有对外接口位于 include/aethermind/model/weight/ 下，src 仅包含对应 .cpp 实现，模块不直接依赖具体 Backend 实现，仅通过 `Backend` 抽象与 `KernelSelector`/`PackingRecipe` 交互。
