模块按职责分层组织，所有头文件位于 `include/aethermind/model/formats/hf/`，对应 `.cpp` 在 `src/model/formats/hf/`：
- I/O 抽象层：`hf_safetensors_file.h` 提供基于 mmap 的零拷贝单文件读取器（`HfSafetensorsFile`），返回共享 `RawStorage` 上的 `RawWeightView`；`hf_safetensors_index.h` 解析 `model.safetensors.index.json` 得到张量到分片的映射（`HfSafetensorsIndex`）。
- 目录编排层：`hf_directory_reader.h` 通过 `InspectDirectory` 识别单文件或分片布局，统一暴露 `ParseConfig` / `LoadRawWeightTable` 两个入口。
- JSON 解析层：`hf_json_reader.h` 中的 `HfJsonReader` 是零拷贝顺序解析基类，供 config.json 与 index.json 复用；`hf_model_config.h` 将 JSON 投影为 `HfModelConfig`（含 RoPE 枚举与字段）。
- 语义层：`hf_tensor_resolver.h` 将 HF 原始张量名映射为逻辑权重视图（如 tied embedding alias），输出 `ResolvedModelWeights`。
- 验证层：`hf_model_validator.h` 以三阶段静态校验（config → raw weight set → resolved model）对接 `ModelValidationOptions`。
- 工具层：`hf_utils.h` 提供 dtype 转换、路径格式化、symlink 拒绝等共享辅助。
依赖方向自下而上：utils → safetensors/index → json_reader → directory_reader → tensor_resolver → validator，上层不反向依赖底层 I/O。错误统一通过 `StatusOr<T>` 返回，避免异常。
