- 每个 CMake 脚本均以 `include_guard(GLOBAL)` 开头，并以 `aethermind_` 前缀导出函数或变量，避免重复包含。
- 对外部可选能力（如 AVX2、F16C、Sanitizer）均采用「先编译探测，再设置布尔开关，最后通过配置函数将编译选项附加到源文件」的模式。
- 用户输入（路径、整数、枚举值）在进入逻辑前先做类型与范围校验，失败时统一通过 `message(FATAL_ERROR ...)` 退出。
- 共享依赖获取采用 FetchContent 声明 + 独立 `-P` 脚本两阶段分离，脚本内部通过 `file(LOCK ... GUARD PROCESS)` 串行化并发写入，并使用临时目录 + `file(RENAME)` 实现原子发布。
