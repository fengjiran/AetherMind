模块分为两层：IR 核心与优化 Pass。
- IR 核心（graph.h / graph_types.h / graph_op_builder.h）：以 `ModelGraph` 为 DAG 容器，节点/值/输入/输出分别由 `GraphNode`、`GraphValue`、`GraphInput`、`GraphOutput` 描述，标识符和算子参数通过 `OpType`、`TensorSpec`、`OpParams`、`WeightBinding` 等类型表达；`AddNode` 在加入前调用 `InferOperator` 做形状推断与 schema 校验，并提供 `Validate()`、拓扑排序等只读查询。
- 优化层（optimization/）：基于 `GraphRewriteSession` 的不可变源图 + 增量 delta 重写模型，支持 `RemoveNode`、`RedirectInput`、`ReplaceValue`、`SubgraphReplacement` 四类原子操作，最终通过 `Commit()` 产出新的 `ModelGraph`；所有 Pass 仅通过 `GraphRewriteSession` 视图访问图，不直接修改 `ModelGraph`。
- Pass 接口：`GraphPass` 抽象类提供 `Name()` 与 `Run(GraphRewriteSession&, PassContext&) const noexcept`，`GraphPassManager` 维护有序 Pass 序列并支持每 N 步 checkpoint 快照；具体 Pass 包括 `ConstantFoldingPass`、`DeadCodeEliminationPass`、`QkvLinearFusionPass`、`GateUpLinearFusionPass`、`SiluMulFusionPass`、`AddRmsNormFusionPass`。
- 常量折叠子系统：`ConstEvaluator` 采用 Plan/Evaluate 两阶段契约，Plan 负责可行性检查与布局规划并返回保守上界 `FoldingCost`，预算由 `CheckFoldingBudget` 集中执行；`FindConstEvaluator(OpType)` 通过静态注册表查找 evaluator。
- 依赖方向：优化层 → graph_rewrite → graph/graph_types；const_evaluator 依赖 operators/op_params 与 shape_inference，但不反向依赖优化层。
