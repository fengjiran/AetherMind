- 脚本通过 `ROOT = Path(__file__).resolve().parents[1]`（Agent Memory 相关脚本用 `parents[2]`）定位仓库根目录，避免依赖当前工作目录。
- 可重复性通过 SHA256 文件指纹 + git commit/diff 快照 + 动态库 `ldd` 解析来声明，而非记录绝对路径。
- 外部依赖的版本以显式常量字典（如 `VERSIONS`）声明并在运行时比对，不匹配时抛出结构化错误。
- 校验类脚本采用 `verify_*.py` 命名并与对应 `run_*`/`generate_*` 脚本成对出现，将输入输出结构抽到独立的 contract 模块（如 `verify_model_benchmark.py`）。
- Markdown frontmatter 解析统一使用自定义 `_extract_frontmatter` / `_handoff_metadata` 函数，并为缺失字段提供默认值（如 `schema_version=1.0`、`status=active`）。
