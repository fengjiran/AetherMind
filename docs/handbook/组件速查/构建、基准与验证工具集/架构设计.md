该模块是扁平的脚本集合，按职责分为四类：
- 基准与性能：`run_model_benchmark.py` 通过 `verify_model_benchmark.py`（作为 contract 模块）定义输入输出契约，收集 git 源码快照、SHA256 模型身份、ldd 动态库绑定和机器拓扑信息，并以 JSON 持久化完整可复现性证明；`generate_llama_numerical_reference.py` 依赖 `generate_fp32_admission_hf_fixtures.py` 从 HuggingFace 生成 CPU FP32 Llama 参考张量，并通过版本锁定 torch/transformers/numpy/safetensors。
- 测试驱动：`run_add_op_tests.sh`、`run_broadcast_tests.sh`、`archive_old_handoffs.sh` 等 shell 脚本封装 CTest/pytest 子命令，供 CI 或开发者直接调用。
- 校验器：`verify_cpu_isa_build.py`、`verify_ctest_report.py`、`verify_docs.py`、`verify_model_benchmark.py`、`verify_llama_numerical_reference.py` 分别断言构建产物、测试报告、文档链接和基准/参考数据的契约。
- Agent Memory 契约：`agent_memory/contract_check.py` 解析 AGENTS.md 与 docs 下各 Markdown frontmatter，维护 `.cache/agent_memory/evidence` 下的基线快照，用于保证 agent memory/handoff 工作流文档一致性。
所有脚本均以 `#!/usr/bin/env python3` 入口、相对路径通过 `Path(__file__).resolve().parents[1]`（或 parents[2]）定位仓库根，不安装为包，依赖方向单向指向被测代码与 fixtures。
