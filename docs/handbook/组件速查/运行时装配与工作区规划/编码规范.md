- 资源型类（如 Runtime）将构造函数设为 private 并通过 friend 类（RuntimeBuilder）构造，外部只能通过 Builder 获取实例。
- 可选能力以嵌套 struct 形式组织在 RuntimeOptions 下（allocator/backend/execution/workspace/tracing/kv_cache），每个子结构封装一组布尔开关与尺寸参数。
- 可失败操作同时提供 abort 版与 StatusOr 版入口：RuntimeBuilder 暴露 Build() 与 TryBuild()，KVCacheManager 访问也通过 is_initialized() 判空，调用方负责序列化。
- 需要长期生存期的资源（后端、分配器、KVCacheManager）采用按需懒初始化 + 内部缓存的模式，Get* 方法直接返回引用或指针而非复制。
