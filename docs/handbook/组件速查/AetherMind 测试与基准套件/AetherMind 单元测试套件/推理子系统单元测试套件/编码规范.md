- C++ 用例通过继承 `testing::Test` 的类 + `TEST_F` 宏组织，并在 `namespace { ... }` 内匿名命名空间定义 fixture 工厂函数。
- 对外部二进制或数据目录的访问统一通过环境变量（`AETHERMIND_TEST_MODELS_DIR`、`AETHERMIND_TEST_NUMERICAL_DIR`、`AETHERMIND_INFER_BINARY`）解析，而非硬编码路径。
- 内存与 hugepage 故障注入通过 `ScopedMallocFailure` / `ScopedHugePageAdviceFailure` 作用域对象完成，禁止嵌套且每个线程仅一个活动作用域。
- CLI 契约测试在 Python 中先校验 `AETHERMIND_INFER_BINARY` 存在且可执行，再逐一检查 fixtures 目录下 `config.json` 与 `model.safetensors` 是否就绪。
- 数值对比测试将期望结果以固定轨迹形式声明为结构体数组（如 `FixtureCase`、`RepeatedGeneration`），并用 `ValidateReference` 与 `MakeCpuCompileOptions` 驱动比对。
