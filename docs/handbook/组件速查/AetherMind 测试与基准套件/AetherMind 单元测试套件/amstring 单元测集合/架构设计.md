测试按被测组件划分到独立文件：
- test_basic_string.cpp / test_basic_string_core.cpp：针对 `BasicString`/`BasicStringCore` 接口与分配器语义（含自定义 `StatefulAllocator`）。
- test_char_layout_policy.cpp / test_generic_layout_policy.cpp / test_default_layout_policy.cpp：分别验证 `CharLayoutPolicy`、`GenericLayoutPolicy` 与 `DefaultLayoutPolicy` 的选择逻辑和静态常量。
- test_basic_string_differential.cpp：将 `BasicString` 与 `std::basic_string` 进行差异比对测试。
所有用例均通过 `<gtest/gtest.h>` 组织为 `TEST`/`TYPED_TEST`，并通过 `using namespace aethermind;` 直接引用被测命名空间。
