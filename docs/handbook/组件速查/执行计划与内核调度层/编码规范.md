- 公共入口函数返回 `Status` 或 `StatusOr<T>`，错误语义集中在 `aethermind/base/status.h`，不抛异常。
- 对外 API 标注 `noexcept`，将错误通过返回值传播，保证执行热路径可被内联与向量化。
- 所有可调度的数据结构（`ExecutionPlan`、`ExecutionBindingPlan`、`PreparedExecutionBindings`）通过 `friend` 把创建工厂暴露给对应 .cpp 中的自由函数，构造器私有化以实现 RAII 与不变式封装。
- 跨阶段对象通过 `IsCompatible` 与 `binding_key()` 进行冷路径身份校验，防止在计划变更后复用旧绑定。
- 状态与 KV 相关标识使用模块内枚举（`ExecutionValueKind`、`ExecutionKVCacheSlot`、`KVAppendLayerState`），与图 IR 的 `GraphValueId` 解耦，避免执行期反向依赖编译期结构。
