- ShapeSymbol 的构造区分 CreateFromValue（静态非负）、Create（生成新符号，值为 -N）与 Unknown（-1），并通过原子计数器保证符号互异。
- ShapeSymbol 与 SymbolicShape 上的二元运算成对出现：Join 用于控制流分支合并（宽松），Unify 用于算子输入对齐（严格并返回 StatusOr）。
- 形状约束采用 sum-type 设计：所有具体约束派生自统一的 ConstraintVariant，并通过 ShapeConstraint 包装 error_context 诊断信息。
- 约束求值统一返回 ShapeConstraintEvaluationResult 三态 {kSatisfied, kViolated, kDeferred}，其中 kDeferred 表示当前事实不足以判定。
- 对外 API 普遍使用 AM_NODISCARD 标记并返回 StatusOr<T> 或 Status，错误走 aethermind/base/status.h 的错误码而非抛异常。
- 数据-only 结构体（DimLocator、TensorPort、DeferredBroadcastAxis 等）默认启用 operator<=> 以获得自动生成的相等与排序语义。
