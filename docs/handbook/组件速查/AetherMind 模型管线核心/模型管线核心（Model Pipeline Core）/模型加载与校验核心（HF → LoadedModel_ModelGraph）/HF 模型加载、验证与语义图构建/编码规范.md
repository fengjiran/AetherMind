- 对外 API 一律返回 `StatusOr<T>`，失败信息携带错误码而非抛异常。

- 校验逻辑拆分为多阶段静态方法（ValidateConfig/ValidateWeightSet/ValidateResolvedModel），由 `ModelValidationOptions` 驱动宽松/严格策略切换。
- 对每类结构体使用 Doxygen 风格的 `/// @brief` / `/// @param` / `/// @return` 注释说明契约、不变量与错误语义。
