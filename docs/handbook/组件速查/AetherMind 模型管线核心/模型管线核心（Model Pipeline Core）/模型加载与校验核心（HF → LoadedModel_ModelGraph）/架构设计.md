以 `model_loader.h` 为顶层入口，串联 `formats/hf/`（HF 目录/JSON/safetensors 读取与索引）、`weight/`（raw_weight 存储、FP32 转换、packing 请求与 binding 解析）以及图构建层（`build_model_graph` / `llama_dense_graph_builder` / `transformer_graph_common`），最终产出 `loaded_model.h` 中的 LoadedModel 与 `resolved_model_weights.h` 中按语义绑定的权重集合；`model_validation_options.h` + `hf_model_validator` 在三阶段（结构/数值/一致性）贯穿整个流水线，使 I/O、格式转换与图构建共享同一份约束与错误路径。
