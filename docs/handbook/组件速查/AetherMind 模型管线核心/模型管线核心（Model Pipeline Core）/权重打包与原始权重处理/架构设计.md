模块以四个独立头文件划分职责，均位于 `aethermind/model/weight` 命名空间下：
- `weight_packing_request.h` 定义跨编译期与准备期的 `WeightPackingRequest` 数据载体（含 OpType、source_id、value_index、binding、components、selector、recipe）。
- `packed_weight_collection.h` 通过 `WeightArtifactKey = {source_id, value_index, binding, selector, recipe}` 作为唯一键管理 `PackedWeight` 共享所有权集合，并提供 `PrepackWeightRequests` 批量执行后端 `PackWeights` 的入口；集合受单 source_id 冻结约束且与 `ExecutionPlan` 共享 artifact 生命周期。
- `weight_binding_resolver.h` 暴露唯一的 `ResolveWeightBinding`，将 `WeightBinding` 映射到 `ResolvedModelWeights` 中的 `RawWeightView`，是复合绑定（Qkv/GateUp）与 lm_head tied 回退的统一决策点。
- `raw_weight_storage_usage.h` / `raw_weight_fp32_conversion.h` 分别负责只读存储用量统计与一次性 CPU 侧 F16/BF16→FP32  widening 转换，两者共享 `RawWeightStorageUsage` 结构体并遵循相同的 owner-aware 去重语义。
依赖方向单向向外：本模块依赖 `backend/packed_weight`、`graph/graph_types`、`model/raw_weight` 等底层类型，但自身不持有具体 backend 实现，仅通过 `Backend::PackWeights` 接口解耦。所有对外 API 返回 `StatusOr<T>`，失败路径保证无副作用。
