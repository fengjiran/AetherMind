- 每个自定义浮点类型（Half、BFloat16、Float8*）都提供 `from_bits_t` tag + `from_bits()` 工厂以从原始位模式构造，同时暴露 `bits()` 读取器，区分“语义转换”和“位直通”。
- 算术运算符通过对 `float`/`double` 隐式转换后运算再窄化回目标类型，使 NaN 遵循 IEEE 754 binary32 语义，而非在位级直接计算。
- 对非标准格式（如 bfloat16）将 `std::numeric_limits` 的 `is_iec559` 设为 false，以明确表达其不满足完整 IEEE 754 标准。
- 类型判别通过 `DataType::IsFloat*` / `IsInt` / `IsBool` 等方法集中进行，而非在调用方重复比较 `code()`。
- 跨类型转换的溢出检查集中在 `cast.h` 中按 From/To 的 integral/floating-point/complex 重载族分发，并由 `only_need_real` / `maybe_real` 模板在 complex→非 complex 时自动提取实部。
