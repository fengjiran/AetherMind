该模块按 `include/aethermind/operators/` 头文件与 `src/operators/` 实现一一对应组织，分为三层：
- 共享语义层（shared_schema_layer）：`op_type.h/.cpp`、`op_params.h/.cpp`、`operator_schema.h/.cpp`、`operator_name.h/.cpp`、`op_params_serde.h/.cpp` 定义算子枚举、参数变体、端口 Schema 与名称映射，供所有算子共用。
- 推理接口层（math_ops）：`operator_inference.h/.cpp` 与 `inference_result.h` 提供 `InferenceResult` 抽象和静态/符号形状与 dtype 推断的公共框架。
- 算子实现层：`ops/*.h` + `ops/*.cpp` 每对文件对应一个具体算子（add、matmul、attention、rope、softmax、kvcache_update 等），通过注册机制接入共享的类型与 Schema 体系，并复用 rope_frequency_resolver 完成 RoPE 频率表构造。

跨子模块的关键契约是：每个算子对外暴露 `OpType` 标识、`OpParams` 变体、`OperatorSchema` 描述以及 `infer_shape/dtype` 钩子，由上层执行引擎通过统一接口调度，从而实现算子定义与后端实现的解耦。
