- 优化 Pass 实现为无状态类，继承 `GraphPass` 并通过 `GraphRewriteSession` 视图修改图，禁止直接访问底层 `ModelGraph` 成员。
- 常量折叠遵循 Plan/Evaluate 两阶段契约：`Plan` 只做可行性检查与布局描述并上报保守 `FoldingCost`，预算判断集中在 `CheckFoldingBudget`，`Evaluate` 保持无状态且不接受持久引用。
- 图的变更通过 `GraphRewriteSession` 的原子操作（RemoveNode/RedirectInput/ReplaceValue/SubgraphReplacement）批量提交，再由 `Commit()` 统一物化并可选地剪枝不可达残留。
- `GraphPassManager` 通过 `unique_ptr<GraphPass>` 拥有 Pass 生命周期，Pipeline 配置使用 fluent Add/AddSequential/SetCheckpointEvery 链式 API。
- 公共头文件用 Doxygen 风格注释描述不变量、所有权与线程安全约定，并在文档中交叉引用设计文档（如 model_graph_design_v2.md §10/§15/§16.4）。
