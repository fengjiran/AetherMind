- 每个算子目录采用 entry/internal/reference 三件套：entry 负责参数构建与注册，internal 声明内核接口，reference 提供 FP32 标量验证实现
- 内核通过 `KernelRegistry::Global().Register(...)` 在文件作用域静态注册，并以 OpType + KernelSelector 作为查找键
- 对权重形状、步长与元素计数的溢出检查统一走 `CheckOverflowMul/Add` 与 `ContiguousWeightByteSize`，错误以 `Status::InvalidArgument`/`Overflow` 返回
- 向量化实现与标量实现通过 `CpuCapabilities` 中的 feature mask 与 `KernelSelector` 共同筛选，而非运行时分支
