本模块是算子层的纯头文件 ABI，被后端实现、图构建与调度等上层共同依赖，内部按职责划分为四个正交面：
- 算子身份：`op_type.h` 定义 `OpType` 枚举（Embedding/RMSNorm/Linear/QkvLinear/MatMul/RoPE/Attention/Silu*/*CacheUpdate/Add/Softmax/Argmax/Reshape/Permute/Reorder/GateUpLinear），并提供 `ToString` 与 `std::hash` 特化，作为所有后续组件的统一分发键。
- 算子参数：`op_params.h` 以强类型结构体表达各算子参数，RoPE 通过 `RoPEAlgorithmParams = std::variant<StandardRoPE, LinearRoPE, DynamicNtkRoPE, YarnRoPE, Llama3RoPE, LongRoPE>` 与 `RoPEAlgorithm` tag 解耦算法选择；`rope_frequency_resolver.h` 在此基础上给出与后端无关的频率表计算 API（静态 vs 动态 NTK/LongRoPE 两条路径）。
- 算子 Schema：`operator_schema.h` 用 `OperatorInputPort`/`OperatorOutputPort` + `OperatorTraits` + `StateAliasPortPair` 描述每个 OpType 的端口顺序、角色（ModelInput/Activation/Weight/Constant/State）、副作用/确定性/可编译期求值等属性，并由 `GetOperatorSchema`/`GetOperatorSchemas` 暴露静态注册表；KV 缓存端口名通过 `kv_cache_ports` 命名空间集中声明，保证 schema 与验证逻辑一致。
- 推理与序列化：`operator_inference.h` 暴露 `InferOperator` 主入口及 per-op `InferXxx`（在 `aethermind::detail` 下），返回带运行时检查的 `InferenceResult`；`op_params_serde.h` 提供 `SerializeOpParams`/`ParseOpParams` 的稳定文本格式，并将 Reshape shape 与 Permutation 的序列化暴露为独立函数供诊断输出复用。
依赖方向单向向外：本模块仅依赖 `aethermind/base/*`、`utils/*` 与 `shape_inference/*`（TensorSpec/ShapeConstraint），不反向引用任何后端或图构建实现，从而构成稳定的跨层契约。
