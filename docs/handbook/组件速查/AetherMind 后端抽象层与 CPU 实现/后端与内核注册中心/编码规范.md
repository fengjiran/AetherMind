- 后端创建统一通过 `BackendFactory::Create()` 返回 `StatusOr<std::unique_ptr<Backend>>`，使能力检测失败以 `Status` 形式向上传播而非抛异常。
- 内核注册采用 `AM_REGISTER_KERNEL(unique_name, descriptor)` 宏，在匿名命名空间内定义静态布尔变量并在其 IIFE 中调用 `RegisterKernel`，借助构造函数顺序保证进程启动时完成注册。
- `BackendRegistry` 对 `factories_` 与 `backends_` 两个 `unordered_map` 同步失效：`SetFactory` 同时 erase 同 device_type 的已缓存 backend，保证工厂替换后下次 `GetBackend` 重建。
- CPU 后端将逻辑权重组件沿 axis=0 融合打包，单一 artifact 承载所有 component，并通过 `PackingRecipe` + `AllocationRequest` 描述布局与对齐要求。
- 重量形状/步长/字节数计算一律通过 `CheckOverflowMul` / `CheckOverflowAdd` 进行 int64_t 溢出检查，溢出路径返回 `Status::Overflow`。
