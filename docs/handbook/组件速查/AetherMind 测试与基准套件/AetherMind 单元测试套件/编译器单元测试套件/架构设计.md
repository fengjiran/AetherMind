测试按被测子系统的目录结构组织：
- `test_model_compiler.cpp`：通过 `ModelCompiler::LoadAndCompile` / `Compile` 端到端验证从 HuggingFace 模型到 `LoweredGraph` 的完整编译流程，覆盖 O0/O2 优化级别、权重打包、RoPE 配置传播以及 dtype 校验。
- `lowering/test_graph_lowering.cpp`：直接构造 `ModelGraph` 并调用 `LowerModelGraph`，断言 `LoweredGraph` 的步骤拓扑、selector（device_type/phase/weight_format）及值绑定正确性。
- `optimization/test_semantic_optimization_pipeline.cpp`：使用 `graph/optimization/test_optimization_helpers.h` 中的 `AddFloatConstant` / `AddElementwiseAdd` / `AddSilu` 等辅助函数拼装复合图，分别以 `PassContext::opt_level = 0/1/2` 驱动 `OptimizeModelGraph`，验证 ConstantFolding、DCE、SiLU→Mul 融合、QkvLinearFusion、AddRmsNormFusion 各 pass 的行为边界。
依赖方向单向向上：测试仅包含被测头文件与共享测试助手，不引入额外运行时；所有断言围绕 `StatusOr` 返回值、`ValidateLoweredGraph` 与 `graph.Validate()` 进行。
