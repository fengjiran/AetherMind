模块按职责分为三层：
- 元数据层 `data_type.{h,cpp}`：定义 DLPack 风格的 `DLDataTypeCode` / `DLDataType` 结构体，以及封装了 code/bits/lanes 校验、字节大小、自然对齐、可伸缩向量（vscale）语义的 `DataType` 类，是所有其他类型的统一入口。
- 标量类型层：每个格式一个头文件加对应 `.cpp`，包括 `half.h`（IEEE binary16）、`bfloat16.h`（Brain float）、`float8_e4m3fn.h`、`float8_e5m2.h`，均通过 `std::numeric_limits` 特化暴露常量；`complex.h` 提供 `aethermind::complex<T>` 并注入 `std::` ADL 以兼容 `<complex>` 数学函数；`detail/floating_point_bits.h` 共享位级 FP 操作。
- 转换层 `cast.h`：提供 `is_cast_overflow` / `check_and_cast` 等 constexpr 溢出检测与标量提升工具，被上层 dtype 转换逻辑复用。
依赖方向单向：`cast.h` → 各标量类型；`data_type.h` → 所有标量类型（用于 `IsFloat*` 判定）；标量类型之间仅通过 `detail/floating_point_bits.h` 解耦。`half.h` 在 x86/F16C、ARM NEON、CUDA 路径下有条件包含硬件头，但默认保持纯整数位操作的便携实现。
