- 对外构造 API 统一采用私有构造函数配合 `static StatusOr<T> Open(...)` / `Load(...)` 工厂方法，使解析失败以 `Status` 形式返回而非抛异常。
- 所有可能失败的 I/O 与解析函数返回 `StatusOr<T>`，调用方通过检查状态码消费结果。
- HF config.json 字段在 `HfModelConfig`/`HfRopeConfig` 中以 1:1 同名成员表示，缺失字段保持默认零值并由上层消费者推导或拒绝。
- 枚举类型使用固定大小的 `uint8_t` 作为底层类型（如 `HfDirectoryLayout`、`HfRoPEAlgorithm`），并通过独立的 `ParseXxx` / `ToString` 成对函数在字符串与枚举间转换。
- 需要跨子组件复用的辅助函数放在 `aethermind::hf` 命名空间下的 `hf_utils.*` 中，包括 dtype 解析、路径消息格式化与 symlink 拒绝。
- 对象生命周期与资源绑定遵循 RAII：`HfSafetensorsFile` 持有 `shared_ptr<const RawStorage>`，其 `Find` 返回的指针仅在对象存活期间有效。
