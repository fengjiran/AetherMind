- 新算子在 `OpType` 枚举中新增一个条目后，需在 `ToString`、`OperatorSchema` 静态表与 `InferOperator` 分发处同步补充，三者缺一即导致运行期不可识别。
- 算子参数采用强类型 POD 结构体配合 `std::variant` 表达可选算法族（如 `RoPEAlgorithmParams`），并通过独立的 `GetRoPEAlgorithm` 访问器从变体提取 tag，避免 tag 与 payload 字段各自维护。
- 算子间的共享常量（KV cache 端口名、RoPE 配对/算法名称等）集中在头文件的内联 `inline constexpr` 或命名空间中，由 schema 定义与验证代码共同 include，禁止散落的魔法字符串。
- 需要持久状态的算子通过 `StateAliasPortPair` 将同名 state input/output 绑定到同一物理缓冲区，schema 成为 lowering 阶段生成别名记录的单一事实来源。
- 算子推断函数的失败路径统一返回 `Status`/`StatusOr<T>`，成功时输出附带 `runtime_checks` 中的 `ShapeConstraint`，而非抛出异常。
- 算子参数的序列化与诊断输出共享 `SerializeReshapeShape`/`SerializePermutation` 等工具函数，确保文本规范只有一份实现。
