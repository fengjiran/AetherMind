三个子目录（rope/、argmax/、embedding/）遵循相同的两文件结构：`*_internal.h` 仅声明 POD 参数结构体与 `Run*Reference` 微内核入口；`*_entry.cpp` 在 `aethermind::cpu::detail` 命名空间内实现 `Build*Metadata`（用于 `KernelParamsBuildContext.attrs` 的持久化元数据）、`Build*F32ReferenceArgs`（从 `KernelContext.inputs/outputs` 解析并校验 TensorView，通过 placement new 写入 `params_buffer`），以及最终注册的 `KernelEntry`。

- rope/：除 entry 与 internal 外还包含 `rope_f32_reference.cpp`，承载具体旋转计算；metadata 以 `RoPEF32KernelMetadata` 头 + 紧随其后的逆频率表字节序列组织，支持 Standard/Linear/DynamicNtk/Yarn/Llama3/LongRoPE 多种算法并通过 `std::visit` 分发填充。
- argmax/：同样含 `argmax_f32_reference.cpp`，将冻结的 axis 存入 attrs，运行时按输出轴展开 shape/stride。
- embedding/：纯 reference 路径，同时暴露 `BuildEmbeddingF32PackedIdentityArgs` 用于 packed weight identity 变体。

依赖方向单向指向 `backend/kernel_context.h`、`kernel_static_registration.h`、`operators/op_params.h` 等上层基础设施，不反向被 operator 层 include internal 头。
