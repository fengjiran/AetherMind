- 每个算子目录采用 `_entry.cpp` / `_internal.h` / `_f32_reference.cpp` 三件套结构，reference 实现作为正确性基准和 fallback。
- SIMD 特化文件以 ISA 后缀命名（如 `*_avx2.cpp`、`*_scalar.cpp`），并通过统一调度接口按 `CpuCapabilities` 选择。
- 重量布局以 `constexpr PackingLayout` 常量加独立 `kCpu*Alignment` 常量表达，布局变化需引入新 identity 而非修改旧值。
- 容量与形状计算一律通过 `CheckOverflowMul`/`CheckOverflowAdd` 显式溢出检查，失败返回 `Status::Overflow`。
- CPU 能力相关类型（`CpuFeatureSet`、`CpuFeaturePolicy`、`CpuCapabilities`）保持无分配、可拷贝、`noexcept` 语义，便于嵌入寄存器/缓存。
