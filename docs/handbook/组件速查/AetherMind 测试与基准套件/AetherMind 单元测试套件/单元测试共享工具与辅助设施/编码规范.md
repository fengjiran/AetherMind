- 张量断言函数返回 `::testing::AssertionResult`，并在 mismatch 数量超过 `max_report` 时截断错误消息以避免输出爆炸。
- 类型分发采用按 `DataType` 的 if-else 分支显式特化 float32/double/half/bfloat16/int32/int64，未支持的 dtype 直接返回失败或抛出异常。
- 张量构造统一走 `detail::ComputeRequiredBytes` + `detail::MakeBuffer`，先计算 `max_element_offset + 1` 所需字节数再 `posix_memalign` 分配。
- 随机张量生成以 `kDefaultTensorRandomSeed = 123456789ULL` 为默认 seed，确保单测结果可复现。
- 测试用分配器以静态局部变量或 `std::shared_ptr<ResourceAllocationStats>` 持有状态，便于跨多个 Buffer 的生命周期追踪分配序列。
