文档按主题分层组织，无代码依赖：
- `designs/` 存放核心子系统的设计方案（推理会话、模型图、KV Cache、统一分配器、算子评估器等），是运行时实现的权威设计来源。
- `operators/` 以算子维度划分（gemm、rmsnorm、rope、embedding 等），每个算子目录包含 README、优化说明与对应基准结果，体现算子契约优先的组织方式。
- `tests/` 与 `improvement-plan/` 分别存放测试验证报告与编号改进计划，命名采用 `YYYY-MM-DD` 日期后缀保证可排序。
- `agent/` 下维护 AI Agent 的工作流产物：`decisions/ADR-*` 记录架构决策，`handoff/` 按 workstream 归档会话产物，`prompts/` 提供 prompt 模板。
- `api/` 定义对外 C ABI 与 Doxygen 基线；`guides/` 编码风格、注释、测试编写指南；`archive/` 保存已废弃的早期设计。
- `templates/` 与 `agent/prompts/` 提供可复用的文档与 prompt 模板，形成“模板 → 产出”的生产链。
