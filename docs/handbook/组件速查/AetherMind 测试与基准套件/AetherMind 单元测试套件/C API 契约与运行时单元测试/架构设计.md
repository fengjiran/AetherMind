测试分为三层：
- 契约层：`test_c_api_contract.{c,cpp}` 通过 `extern "C"` 链接 `AetherMindCErrorContract` 与 `AetherMindCConfigLayout`，并用 `static_assert(std::is_standard_layout_v<am_config_t>)` 等编译期断言校验 ABI 结构体布局、函数签名与类型不可转换性，确保 C/C++ 双方对 `am_config_t`/`am_session_config_t` 的内存布局一致。
- 消费者桥接层：`test_c_api_runtime_consumer.{c,h}` 暴露纯 C 函数 `AetherMindRunCInference`，把高层 `ModelLoader`/`RuntimeBuilder`/`ExecutableModel`/`InferenceSession` 封装成仅依赖 `c_api.h` 的调用入口，模拟外部 C 应用。
- 集成测试层：`test_c_api_runtime_integration.cpp` 使用 `TestWithParam<CAbiFixtureCase>` 参数化覆盖 f32-missing/auto/explicit/tied × O1Plain/O2Packed 八种组合，并通过独立的 `DirectSessionGenerate`（直接构造内部 C++ session）作为期望值，断言 C 路径输出与之完全一致；另含 `test_c_api_error.cpp`、`test_c_api_runtime_smoke.c`、`test_c_api_runtime_helpers.h` 分别覆盖错误处理与轻量 smoke 场景。
依赖方向单向向下：集成测试 → 消费者桥接 → c_api.h → 核心 C++ 库；契约测试不加载模型，只检查符号与布局。
