- 内核入口函数统一返回 `Status` 并以 `noexcept` 标注，错误通过 `Status::InvalidArgument` 表达参数非法。
- SIMD 优化路径使用条件编译（如 `GEMM_HAS_AVX2_FMA_KERNEL`）与 reference/scalar 候选分离，由上层选择最优实现。
- 参数结构体置于 `_internal.h` 头文件中并在命名空间 `aethermind::cpu::detail` 下声明，对外仅暴露 `Run*` 入口函数。
- MatMul 等高层算子在 `*_entry.cpp` 中通过 `AM_REGISTER_KERNEL` 完成 op_type/device/dtype/format 选择器与 `params_builder`/`metadata_builder` 绑定。
- 输入合法性检查采用先 shape/stride 推导、再调用 `ValidateLayoutInjectivity` 与 `ValidateStridedDisjoint` 的固定顺序，零元素输出直接跳过内存布局校验。
