每个子目录（linear/、qkv_linear/、gate_up_linear/）遵循统一的三文件结构：
- `*_internal.h` 定义不可变的 `*F32KernelMetadata`（从 op_params 派生的输出特征拆分）与 `*F32KernelArgs`（预验证的指针 + stride + 维度），并声明 `Run*F32Reference` 入口；对 QKV/Gate-Up 还通过 `PackedGemmF32Args` 暴露可选的 `Run*F32PackedB` AVX2-FMA 分支。
- `*_entry.cpp` 在 `aethermind::cpu::detail` 命名空间内注册 KernelParamsBuilder，实现 `Build*F32ReferenceArgs`：解析 `KernelParamsBuildContext` 的 inputs/outputs/packed_weight/attrs，使用 `AnalyzeRowwiseView` + `ValidateRowwiseOutputLayout` + `ValidateRowwiseDisjoint` 完成布局分析与内存重叠检查，再以 placement-new 构造参数对象。
- `*_f32_reference.cpp` 仅包含纯标量三重循环 GEMM 参考实现。
依赖方向单向向下：entry → internal.h → gemm_internal.h；不反向依赖上层算子，仅消费 `kernel_context.h`、`kernel_types.h`、`kernel_static_registration.h`、`packed_weight_validation.h` 等公共后端基础设施。
