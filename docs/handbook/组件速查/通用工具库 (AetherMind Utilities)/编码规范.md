- 对外暴露的算术/转换 API 采用 `(in, out) -> bool overflowed` 形式，成功时写入 `out` 且返回 `false`，失败时保留 `out` 原值并返回 `true`。
- 所有公开 API 标记为 `noexcept`，将异常与溢出两类错误解耦：异常由 `AM_CHECK`/`AM_DCHECK` 处理，返回值表示可恢复的错误状态。
- 整型工具通过 `detail::` 内部命名空间放置平台相关实现（如 `CheckOverflowMulPortable`），对外只暴露模板函数统一入口。
- 标准库特性扩展（如 `std::hash`）通过在 `std` 命名空间提供显式模板特化进行注入，而非修改上游类型。
- 头文件统一使用 `AETHERMIND_UTILS_<NAME>_H` 形式的 include guard，并以 Doxygen `@file` 注释说明职责。
