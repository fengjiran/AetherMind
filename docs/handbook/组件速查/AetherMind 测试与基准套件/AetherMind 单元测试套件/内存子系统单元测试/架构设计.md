测试目录按被测头文件一一对应组织：test_buffer.cpp 验证 Buffer 的构造/析构、共享所有权与对齐；test_cpu_allocator.cpp 通过 gtest::TestWithParam + INSTANTIATE_TEST_SUITE_P 参数化校验 CPUAllocator 的对齐分配与零长度行为；test_memory_handle.cpp 验证 MemoryHandle 的引用计数、重置与自定义释放器回调；test_memory_format.cpp 断言 MemoryFormat 枚举序值及 channel-last stride 计算；test_memory_junk_fill.cpp 直接测试 memory::detail::FillMemoryJunk 的边界保留语义。所有用例统一使用 gtest，并通过 include "inference/test_malloc_interposer.h" 拦截全局 new/delete/free，以在可控环境下验证内存管理路径。
