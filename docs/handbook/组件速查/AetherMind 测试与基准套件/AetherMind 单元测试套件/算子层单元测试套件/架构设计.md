测试按被测对象分层组织：
- 顶层文件覆盖算子基础设施：`test_op_type.cpp` 验证 `OpType` 枚举到字符串的映射；`test_op_params_serde.cpp` 校验各 `OpParams` 变体的序列/反序列化；`test_operator_schema.cpp` / `test_operator_name.cpp` 校验算子 schema 注册与命名；`test_kernel_context.cpp` / `test_rope_frequency_resolver.cpp` 校验底层辅助组件。
- `test_operator_inference.cpp` 通过统一的 `InferOperator` + `MakeSpec` 接口对全部 `OpType` 做参数合法性与图级推断回归，并复用 `test_operator_inference_helpers.h` 中的 `MakeSpec`、`ToString` 等辅助。
- `ops/` 子目录为每个算子（Add/RMSNorm/Attention/Linear/MatMul/RoPE/Silu/Softmax/Argmax/Embedding/GateUpLinear/QkvLinear/KVCacheUpdate/Permute/Reorder/Reshape/ElementwiseMul/SiluMul）提供独立推断用例，统一断言支持的 `DataType`、输入维度兼容性与错误码。
依赖方向单向指向被测头文件（`aethermind/operators/*`），测试之间无相互依赖，便于新增算子时仅追加 `ops/test_xxx_inference.cpp`。
