- 每个被测头文件对应一个独立的 test_*.cpp 源文件，文件名与被测模块名一致（buffer、cpu_allocator、memory_handle、memory_format、memory_junk_fill）。
- 测试代码统一使用 `using namespace aethermind;` 并包裹在匿名命名空间内，将实现细节隐藏于局部作用域。
- 对公共 API 的不变量通过辅助函数集中断言（如 ExpectEmptyBuffer / ExpectEmptyHandle），再在各 TEST 中复用。
- 涉及资源分配的用例通过 `#include "inference/test_malloc_interposer.h"` 拦截底层分配器，避免依赖真实堆行为。
- 需要多组输入的用例采用 gtest 的参数化风格：定义 struct 携带 name/nbytes/aligment，配合 TestWithParam 与 INSTANTIATE_TEST_SUITE_P。
