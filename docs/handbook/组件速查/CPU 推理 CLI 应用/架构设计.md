模块由一个独立可执行目标 `aethermind_infer` 构成（见 CMakeLists.txt），入口 `inference_main.cpp` 负责解析 `--model/--tokens/--context-tokens/--max-new-tokens/--eos-token-id/--preset` 等 flag 并构造 `RunOptions`；核心编排逻辑在 `inference_runner.{h,cpp}` 中暴露为同步 API：`ValidateRunOptions` 校验输入与 `HfModelConfig` 的兼容性，`RunInference` 按 `RunStage` 阶段顺序依次创建 Runtime、加载/编译/准备模型、构建 Session 并调用 generate，错误通过 `Status` + `RunStage` 回溯到失败步骤，`std::bad_alloc` 统一转换为 `ResourceExhausted`。依赖方向单向指向底层库 `AetherMind`（含 `base/status.h`、`inference/cpu_inference_options.h`、`inference/inference_session.h`）和日志库 `spdlog`，模块内部不反向依赖上层框架。
