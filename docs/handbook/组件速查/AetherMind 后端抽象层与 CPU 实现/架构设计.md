本模块按三层切分：顶层 `include/aethermind/backend/` 暴露与具体设备无关的契约（`backend.h`、`kernel_def.h`、`kernel_types.h`、`packed_weight.h`、`packing_recipe.h`、`stream.h`、`resolved_kernel.h`、`kernel_context.h`），由 `src/backend/backend_registry.cpp` 中的 BackendRegistry/KernelRegistry 在进程级维护后端工厂缓存与内核候选查询；CPU 实现位于 `src/backend/cpu/`，通过 `CpuBackend` 把 CPU 算子注册表、能力检测、逻辑权重到物理布局的打包以及工作空间分配组装成具体的 `Backend` 实例。上下两层之间仅通过 `backend_factory.h`、`backend_fwd.h`、`kernel_static_registration.h` 等前向声明头解耦，新增设备后端只需提供对应的 Factory 并走静态注册路径，无需改动现有内核与调度接口。
