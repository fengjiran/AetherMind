模块按算子粒度划分为两个并列子目录：
- `gemm/`：定义 `GemmF32Args` / `PackedGemmF32Args` 两种预验证参数结构体（见 `gemm_internal.h`），并暴露 `RunGemmF32Reference`、`RunGemmF32Scalar`、`RunGemmF32Avx2Fma` 以及针对 KC=512、NR=16 的 packed-B 变体 `RunGemmF32PackedB*`。其中 reference/scalar/AVX2-FMA 三种候选通过条件编译（`GEMM_HAS_AVX2_FMA_KERNEL`）分离到 `gemm_f32_reference.cpp`、`gemm_f32_scalar.cpp`、`gemm_f32_avx2.cpp`；packed-B 的 reference 与 AVX2 实现分别位于 `gemm_packed_b_reference.cpp` 与 `gemm_packed_b_avx2.cpp`。依赖方向单向向下：AVX2 路径回退至 scalar，scalar 再回退至 reference。
- `matmul/`：定义带 batch rank 的 `MatMulF32KernelArgs`（见 `matmul_internal.h`），并通过 `matmul_entry.cpp` 中的 `AM_REGISTER_KERNEL` 将 `CpuMatMulF32Reference` 注册为 `OpType::kMatMul` 的 CPU/F32/plain 权重 kernel，`BuildMatMulF32ReferenceArgs` 负责从 `TensorView` 推导 batch 广播形状、步长并调用布局注入性/不相交校验后委派给 `RunMatMulF32Reference`（实现于 `matmul_f32_reference.cpp`）。
两层共享公共基础设施（`aethermind/base/status.h`、`aethermind/backend/kernel_static_registration.h`、`common/alias_utils.h`、`utils/overflow_check.h`），本模块内部不互相依赖。
