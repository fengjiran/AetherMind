模块以 `graph_pass_manager.h/.cpp` 为中心：`GraphPass` 是无状态抽象基类（仅暴露 `Name()` 与 `Run(GraphRewriteSession&, const PassContext&)`），由 `GraphPassManager` 按顺序持有 `std::unique_ptr<GraphPass>` 并在 `Run()` 中依次调用；当 `checkpoint_every != 0` 时，每次 N 次 pass 后将 `GraphRewriteSession.Commit()` 提交为不可变 `ModelGraph` 快照，后续 pass 基于该快照重建 session，从而限制失败传播范围。所有 pass 不得直接访问 `ModelGraph`，只能通过 `GraphRewriteSession` 提供的 `RemoveNode` / `ReplaceSubgraph` / `RedirectInput` / `ReplaceValue` 等 delta 接口进行改写，最终由 `Commit()` 在剪枝后物化为新图。

- 常量折叠子系统：`const_evaluator.h` 定义两阶段 `ConstEvaluator` 接口（`Plan` 描述布局与保守成本估计，`Evaluate` 写入字节）以及 `ConstEvalPolicy` 预算，具体 op 的实现拆分到 `src/graph/optimization/const_eval_add.cpp`、`const_eval_mul.cpp`、`const_eval_silu.cpp`、`const_eval_silu_mul.cpp`，并由 `FindConstEvaluator(OpType)` 静态注册表分发；`constant_folding_pass.cpp` 集中执行预算检查与 buffer 分配。
- 融合 pass：`qkv_linear_fusion_pass`、`gate_up_linear_fusion_pass`、`silu_mul_fusion_pass`、`add_rmsnorm_fusion_pass` 各自继承 `GraphPass`，通过匹配特定子图模式并使用 `ReplaceSubgraph` 替换为融合节点。
- 死代码消除：`dead_code_elimination_pass.cpp` 借助 `op_removability_internal.{h,cpp}` 中的 `IsDceRemovableOp`（封装 `OperatorTraits::has_side_effects` 与 `HasStatefulOutput`）判断可删除性。
- 依赖方向单向向外：pass 实现 → `graph_pass_manager` → `graph_rewrite` → `aethermind/graph/graph`；内部头文件 (`const_eval_internal.h`、`op_removability_internal.h`) 不安装到 include 目录，仅供本模块使用。
