模块以三层内部边界组织：
- 公共头文件位于 include/aethermind/inference/，定义对外 API：ExecutableModel（从 LoweredModelArtifact 准备并持有 ExecutionPlan + ExternalTensorBindings）、InferenceSession（单请求 Prefill+Decode 编排）、WeightPolicy/ModelLoadOptions/GenerationConfig 等策略与配置结构体，以及 ModelResourceUsage / RequestResourceUsage 两类资源使用报告。
- src/inference/ 实现层通过 inference_internal.h 暴露 internal:: 命名空间下的私有辅助函数（ValidateFp32Weights、ValidatePreparedWeights、ValidatePlanContract、ResolveWeightPackingRequests、RunPrefill、RunDecodeLoop），供测试聚焦覆盖失败分支。
- 依赖方向单向向外：本模块依赖 base/status、runtime/runtime_options、execution/*、model/weight/*、compiler/model_compiler.h；被上层 Runtime 与 CLI 消费。ExecutableModel 与 InferenceSession 均不直接持有 Runtime，而是借用其生命周期（Runtime 必须 outlive 二者）。
- 生命周期契约由成员声明顺序强制执行：ExecutableModel 按 artifact → packed_weights → binding_metadata → bindings → plan 的顺序销毁，确保先释放借用后端指针的 plan/binding，再释放底层 backing。
