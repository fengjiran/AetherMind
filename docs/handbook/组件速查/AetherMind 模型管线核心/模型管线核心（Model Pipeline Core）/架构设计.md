本模块按职责划分为三个子层并以 `include/aethermind/model/` 下的头文件作为跨子层契约：
- 顶层 API（`model_loader.h`、`loaded_model.h`、`resolved_model_weights.h`、`build_model_graph.h`、`llama_dense_graph_builder.h`、`rope_params_builder.*`、`transformer_graph_common.*`）定义后端无关的 `RawWeight`、`ResolvedModelWeights`、`LoadedModel`、`ModelGraph` 等类型及构建流程。
- `formats/hf/` 子模块实现 HF 格式的磁盘读取与三阶段校验，产出 `ResolvedModelWeights`。
- `weight/` 子模块提供 FP32 转换、存储用量统计、绑定解析与按 `PackingRecipe` 预打包，输入输出均围绕 `RawWeight`。
- 三者通过顶层头文件解耦：HF 读取器依赖 weight 工具对原始张量做转换/打包，再交由 `model_loader` 组装成 `LoadedModel`；图构建侧 (`build_model_graph` / `llama_dense_graph_builder`) 消费 `LoadedModel` 生成 `ModelGraph`，并通过 `rope_params_builder` 与 `transformer_graph_common` 共享 Transformer 通用参数构造逻辑。
