- 每个优化 pass 派生自 `GraphPass` 并提供 `Name()` 与 `Run(session, ctx)`，且 `Run` 声明为 `const noexcept`，表示 pass 本身无状态且不抛异常。
- Pass 对图的唯一访问通道是 `GraphRewriteSession`，禁止直接读取或修改底层 `ModelGraph`；子图替换统一通过 `ReplaceSubgraph` + `ReplacementNode` / `RewriteOutputBinding` 表达。
- 常量折叠将可行性判定与预算估算放在 `ConstEvaluator::Plan`，内存分配与预算强制执行交给 folding pass，evaluator 自身只报告保守上界成本。
- 可配置性通过 `PassContext` 中的 `enable_*` 标志位控制：pass 在 `Run` 内自行检测标志并早返回，而非从管线中移除，以保证管线结构稳定可观测。
- 共享但不对外暴露的内部逻辑放入 `src/graph/optimization/*_internal.{h,cpp}`（如 `op_removability_internal`、`const_eval_internal`），不在 `include/` 下安装。
