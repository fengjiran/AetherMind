- ABI 兼容性通过 `static_assert(std::is_standard_layout_v<...>)` 与 `extern "C"` 包装函数签名对比来验证，而非仅在运行时断言。
- 集成测试采用「双轨对照」模式：用 C ABI 走一遍推理，再用同一份配置直接构造内部 C++ `InferenceSession` 产生期望结果，再逐字段比对。
- 测试用例以 `TestWithParam<CAbiFixtureCase>` 参数化驱动，将数据集（目录名、名称、CPU preset、packed 标志）与行为解耦。
- 所有对外 C 接口均通过 `struct_size` 与 `abi_version` 字段做版本自检，并在 `ExpectSuccess` 中同时校验 `failure_stage == AETHERMIND_C_INFERENCE_SUCCESS`、`code == AM_STATUS_OK` 与 `output_len` 上界。
