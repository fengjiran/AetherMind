- 每个子目录采用三件套组织：`*_internal.h` 声明内核元数据与参数结构体及 `Run*F32Reference` 原型，`*_entry.cpp` 负责从 `KernelParamsBuildContext` 解析参数并完成布局校验，`*_f32_reference.cpp` 提供纯计算实现。
- 参数结构体只包含可被静态预计算的几何信息（head_dim、stride、shape），而每步可变的缓存指针与位置由 `KVCacheReadBinding` / `KVCacheAppendBinding` 传入，避免把易变状态混入内核参数。
- 对 `TensorView` 输入的统一校验流程：检查 `is_valid()`、`dtype==Float32()`、rank=2、正维度、正步长、非空且 `float` 对齐，再以 `kKernelName` + role 字符串拼接错误消息返回 `Status::InvalidArgument`。
- 缓存目标足迹通过 `storage.token_stride_bytes / sizeof(float)` 与 `storage.head_stride_bytes / sizeof(float)` 推导形状和 strides，并使用 `CheckOverflowMul` / `std::in_range<int64_t>` 防止 int64 溢出后再传给 `BuildStridedAddressFootprint`。
- 写前 alias 安全通过 `BuildStridedAddressFootprint` 构建源/目的 `StridedAddressFootprint`，再用 `ByteRangesOverlap` 证明源与目标、key 与 value 目标之间互不相交，最后才允许内核执行。
