模块以 `model_loader.h` 中的 `ModelLoader::Load` 为唯一对外入口，按三个阶段组织内部管线：
- 读取层 `formats/hf/`：`hf_directory_reader` 负责遍历目录，`hf_json_reader` 解析 `config.json` 为 `HfModelConfig`，`hf_safetensors_file`/`hf_safetensors_index` 打开 safetensors 文件与 index，`hf_tensor_resolver` 将 checkpoint 名称映射到 `RawWeightView`。
- 校验层 `hf_model_validator`：分三阶段 `ValidateConfig` → `ValidateWeightSet` → `ValidateResolvedModel`，由 `ModelValidationOptions` 控制严格度，不触及执行层。
- 视图与绑定层：`raw_weight.h` 定义 `RawStorage`/`RawWeightView` 抽象零拷贝重量；`resolved_model_weights.h` 提供按 Transformer 角色（embed/lm_head/layer→attn/mlp/norm）的结构化视图；`weight_binding_resolver.h` 是唯一将 `WeightBinding` 解析回 `RawWeightView*` 的地方，含 tied lm-head 回退逻辑。
- 产出物：`LoadedModel` 持有 `HfModelConfig` + `ResolvedModelWeights` 作为编译前所有权边界；`build_model_graph.h` 通过 `ParseModelArchitecture` 分发到 `llama_dense_graph_builder` 等 per-family builder，生成 `ModelGraph`。
- 预打包通道：`weight/packed_weight_collection.h` 在准备期通过 `PrepackWeightRequests` 批量调用 `Backend::PackWeights`，并以 `WeightArtifactKey`（source_id+value_index+binding+selector+recipe）为键管理产物，与 `ExecutionPlan` 共享生命周期。
依赖方向单向：loader → formats/hf → raw_weight/resolved → validator → graph builder → packed weight collection，graph/build 阶段反向不引用 loader。
