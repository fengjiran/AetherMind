测试按被测子系统分层组织：
- 根目录 `tests/unit/graph/` 覆盖 `ModelGraph` 基础能力（`test_model_graph.cpp`）、`GraphOpBuilder` 高层 API（`test_graph_op_builder.cpp`）和图序列化（`test_graph_dump.cpp`），共享辅助头 `test_graph_helpers.h`。
- `optimization/` 子目录覆盖 `graph_pass_manager` 与各具体 Pass（常量折叠、死代码消除、RMSNorm/QKV/GateUp/SiluMul 融合等），每个 Pass 一个 `test_*.cpp`，并通过 `test_optimization_helpers.h` 提供可复用的图构建工具（如 `BuildTwoEmbeddingGraph`）。
- Pass 测试通过继承 `GraphPass` 并实现 `Name()` / `Run(GraphRewriteSession&, PassContext const&)` 来定义自定义 Pass，验证 `GraphPassManager` 的调度、错误传播与上下文传递。
- 依赖方向单向：测试仅依赖被测头文件与 `aethermind::test_utils` 中的轻量助手，不引入被测实现。
