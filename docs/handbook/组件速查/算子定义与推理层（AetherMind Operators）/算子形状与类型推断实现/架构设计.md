本模块是 `aethermind::detail` 命名空间下的算子推断层，每个 `.cpp` 文件对应一个算子（如 add、matmul、attention、kvcache_update、rope、softmax 等），仅暴露形如 `InferXxx(const OpParams&, std::span<const TensorSpec>) -> StatusOr<InferenceResult>` 的函数供上层调度。

- 依赖方向：单向依赖上层基础设施 `aethermind/operators/operator_inference.h`（`ValidateInferenceInputCount`、`OpType`、`TensorSpec`、`InferenceResult`、各类 `Dim*Constraint`）以及 `aethermind/shape_inference/broadcast.h`（广播推导）、`utils/overflow_check.h`；不反向依赖执行后端。
- 每个算子通过 `std::holds_alternative<XxxParams>(params)` 校验参数类型，再调用 `ValidateInferenceInputCount(OpType::kXxx, inputs)` 固定输入数量，随后对 `inputs[i].dtype` 使用 `IsXxxSupportedDType` + `MakeXxxUnsupportedDTypeMessage` 进行 dtype 白名单校验。
- 形状推断采用 `SymbolicShape` 与 `ShapeSymbol` 表示静态/动态维度，静态可用 `IsStatic()` / `GetStaticValue()` 直接比较，动态则用 `AreProvablyEqual` 判定相等性，并通过 `HasRank`、广播推导结果中的 `deferred_axes` 将无法在编译期判定的条件以 `DimBroadcastableConstraint` / `DimPositiveConstraint` / `DimEqualConstraint` 形式写入 `InferenceResult::runtime_checks`，留给运行时检查。
- 输出形状由 `InferenceResult::outputs.emplace_back(dtype, SymbolicShape(...))` 构造，或直接复用输入 spec（如 kvcache_update 的 cache-out、silu 的 out）。
