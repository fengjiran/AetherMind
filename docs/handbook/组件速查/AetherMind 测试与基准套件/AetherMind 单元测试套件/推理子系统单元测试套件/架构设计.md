测试按被测包划分为两层：
- `tests/unit/inference/`：对 `aethermind/inference` 与 `aethermind/apps/inference` 内部组件的白盒 gtest 用例（如 `test_executable_model.cpp`、`test_prefill.cpp`、`test_fp32_compatible_inference.cpp`、`test_weight_binding_metadata.cpp`），直接构造 `RuntimeBuilder`、`ModelLoader`、`ExecutableModel` 等被测对象。
- `tests/unit/apps/inference/`：面向应用侧的集成级测试，包括通过进程启动 `aethermind_infer` 的二进制 CLI 契约测试（`test_inference_cli.py`）、Runner 行为与资源生命周期验证（`test_inference_runner*.cpp`、`test_inference_admission_fixtures.cpp`）。

辅助设施集中在同目录头文件中：`test_execution_observation_helpers.h` 提供观测断言，`test_hf_fixed_trajectory_helpers.h` 封装 HF 参考轨迹校验，`test_malloc_interposer.h` 暴露基于 glibc interposer 的 `ScopedMallocFailure` / `ScopedHugePageAdviceFailure` 以注入分配失败。C++ 用例统一使用 `gtest::Test` 类 + `TEST_F` 宏组织；CLI 测试用 Python `unittest.TestCase` 通过 `subprocess` 调用二进制，并通过 `AETHERMIND_INFER_BINARY` 环境变量定位可执行文件。数值回归测试依赖外部 `AETHERMIND_TEST_NUMERICAL_DIR` 与 `.models/inference-admission` 夹具。
