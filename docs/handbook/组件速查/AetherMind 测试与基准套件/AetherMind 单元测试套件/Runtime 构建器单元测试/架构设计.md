本模块由三个独立的 gtest 测试文件组成，均通过 `aethermind/runtime/runtime_builder.h` 暴露的 `RuntimeBuilder`/`RuntimeOptions`/`Runtime` 接口对被测目标进行黑盒验证：
- `test_runtime_builder.cpp`：构造 `StubAllocatorProvider`、`StubBackendFactory` 等最小桩，验证 KV Cache Manager 是否按 `kv_cache.enable_manager` 创建、无效几何/对齐参数返回 `kInvalidArgument`、失败时 `TryBuild` 仍消费已注册的 provider/factory，以及 OOM 注入下 builder 可重试。
- `test_runtime_options_validation.cpp`：使用 `ObservedProvider`/`ObservedBackend`/`ObservedFactory` 观察分配器与后端生命周期，断言不支持的选项（`execution.*`、`workspace.*`、`tracing.*`）和未注册工厂的 GPU 标志在资源创建前即被拒绝并返回 `kUnimplemented`，且允许 `WithOptions` 重试。
- `test_runtime_resource_limits.cpp`：基于 `CPUAllocator` 包装 `ObservedAllocator`，断言 KV payload 预算检查在分配器创建之前执行、越界返回 `kResourceExhausted`、溢出计算返回 `kOverflow`，并在失败后保留注册表以支持重试。
依赖方向单向指向被测头文件及少量测试辅助头（`inference/test_malloc_interposer.h`、`test_utils/test_resource_allocator.h`），不引入运行时实现。
