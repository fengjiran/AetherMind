测试按被测组件分层组织：
- 顶层 `tests/unit/backend/` 验证后端抽象与注册机制：`test_backend_registry.cpp` 通过 `FakeBackend`/`FakeBackendFactory` 注入 `BackendRegistry`；`test_kernel_registry.cpp`、`test_kernel_selector.cpp`、`test_no_hotpath_resolve.cpp` 分别覆盖 `KernelRegistry`、`KernelSelector` 与热路径回退逻辑；`test_backend_weight_packing.cpp` 校验跨后端的权重打包接口。
- `cpu/` 子目录专门测试 CPU 后端及其内部实现：`test_cpu_backend.cpp` 使用 `CpuFeaturePolicy` 控制 ISA 能力，验证 `PrepareKernel`、`GetPackingRecipe`、`PackWeights`；`test_cpu_capabilities.cpp`、`test_cpu_isa_fallback.cpp`、`test_cpu_info.cpp`、`test_cpu_resolve_kernel.cpp`、`test_cpu_workspace_arena.cpp`、`test_cpu_weight_packing*` 等文件对应具体子系统。
- `cpu/kernels/` 聚焦底层算子内核正确性，每个 `test_cpu_*_kernel.cpp` 对应一个内核实现（如 GEMM、RMSNorm、RoPE、SiLU、Attention、Linear/QKV/GateUp），并与 reference 实现做数值对比；`kernels/avx_learning/` 提供 AVX2/FMA 手写参考实现用于性能学习辅助，`kernels/fixtures/rope_hf_v4_57_1.{h,json}` 提供固定 RoPE 测试数据。
依赖方向单向：测试仅 include `aethermind/backend/*`、`aethermind/base/*`、`aethermind/operators/*` 以及被测源码头，不反向依赖生产代码。
