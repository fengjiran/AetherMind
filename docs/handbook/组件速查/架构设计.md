顶层 `CMakeLists.txt` 定义 `AetherMind` 项目并强制 C++20 + `<format>` 可用；通过 `include(cmake/AetherMind*.cmake)` 引入 CPU ISA 探测、Sanitizer 注入、libbacktrace 集成与共享依赖拉取脚本，再 `add_subdirectory(src)` 聚合所有子模块库，并按开关启用 `apps/inference`（CPU CLI）、`tests/unit`（GoogleTest）与 `tests/benchmark`（Google Benchmark）。依赖管理集中在 `.deps/` 与 `cmake_build_system`：spdlog、googletest、google_benchmark 均通过 `aethermind_declare_shared_dependency` / `aethermind_make_shared_dependency_available` 从 GitHub 拉取或复用外部已提供的 target，保证多子模块共享同一份二进制。顶层还暴露 `BUILD_TESTS`、`BUILD_BENCHMARKS`、`BUILD_INFERENCE_TOOL`、`USE_ALLOC_ALIGNMENT`、`BACKTRACE_ON_SEGFAULT`、`BUILD_DOCS` 等全局开关，统一驱动各子模块的可选特性。
