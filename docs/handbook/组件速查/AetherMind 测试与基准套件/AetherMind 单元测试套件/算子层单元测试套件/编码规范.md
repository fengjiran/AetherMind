- 每个算子在 `ops/` 下拥有独立的 `test_<op>_inference.cpp`，以 `TEST(<Op>Inference, ...)` 命名空间组织用例。
- 算子推断测试统一通过 `InferOperator(OpType::kXxx, XxxParams{}, inputs)` 调用，并用 `EXPECT_EQ(...status().code(), StatusCode::kInvalidArgument)` 断言非法输入的错误码。
- 张量规格构造统一使用 `MakeSpec(DataType, shape)`，dtype 遍历使用 `for (const DataType& dtype: k<Xxx>SupportedDTypes)` 模式。
- 全局枚举（如 `OpType`、`DataType`）的字符串化通过 `ToString(...)` 进行断言，且对无效值期望回退到默认表示（如 `Unknown`）。
- 所有测试代码置于匿名命名空间内，并通过 `using namespace aethermind;` 直接引用被测符号。
