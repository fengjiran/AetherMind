测试目录按被测组件一一对应组织：`test_kv_cache_manager.cpp` 覆盖管理器生命周期、初始化失败用例（参数化 `InitFailureCase`）、会话预留/释放；`test_kv_cache_session_view_oom.cpp` 聚焦视图在内存不足时的行为；`test_kv_cache_layout_planning.cpp` 验证静态 KV 布局规划；`test_kv_cache_binding_validation.cpp` 校验层绑定语义；`test_kv_cache_commit.cpp` 覆盖追加-提交流程。公共辅助通过 `test_kv_cache_helpers.h` 暴露，提供 `InitializeAndCommitKVForTest` 以统一填充并提交 K/V 行，使所有测试先写零数据再 commit，避免内核写入依赖。测试通过 `inference/test_malloc_interposer.h` 和 `test_utils/test_allocator.h` 替换分配器，从而可控地注入 OOM 场景。
