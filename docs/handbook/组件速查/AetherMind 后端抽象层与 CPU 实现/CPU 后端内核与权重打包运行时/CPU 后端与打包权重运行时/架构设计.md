模块以 `CpuBackend`/`CpuBackendFactory`（cpu_backend.h/cpp）为对外入口，继承通用 `Backend`/`BackendFactory`，通过 `KernelRegistry` + `CpuCapabilities` 快照按 `effective_features` 过滤候选描述符并冻结为 `ResolvedKernel`。

- 能力子系统：`cpu_capabilities.{h,cpp}` 定义 `CpuArchitecture`/`CpuFeature` 枚举及无分配的 `CpuFeatureSet` 位集；`cpu_info.{h,cpp}` 负责运行时探测，`DetectCpuCapabilitiesOrDie` 在构造路径上 abort，而 `CpuBackendFactory::Create` 走 Status 通道。
- 权重打包子系统：`cpu_packed_weight_layout.{h,cpp}` 声明不可变的 `PackingLayout` 标识（`kCpuIdentityPackingLayout`、`kCpuBPanelF32Kc512Nr16Layout`）与对齐常量，配合 `packed_weight_validation.cpp` 中的 `WeightPackingPlan`/`PlanIdentityWeights`/`PlanBPanelF32Kc512Nr16Weights` 等 plan 函数，将逻辑视图映射为带溢出的物理字节数；`PackWeightsWithRecipe` 是注册表外的打包原语。
- 工作空间：`CpuWorkspaceArena` 继承 `WorkspaceArena`，对一段连续内存做简单线性绑定与 Reset。
- 算子内核组织：`src/backend/cpu/kernels/<op>/` 下每个算子目录遵循三件套——`*_entry.cpp` 暴露 `kernel_entry_<op>` 供注册表使用，`*_internal.h` 定义内部签名，`*_f32_reference.cpp` 提供纯标量参考实现；SIMD 特化（如 `gemm_f32_avx2`、`rmsnorm_f32_avx2`、`dot_product_f32_avx2`）位于 `common/` 或各自目录中，由调度器按 ISA 选择。
- 公共工具：`include/aethermind/backend/cpu/kernels/common/` 提供 activation/broadcast/alias/layout/simd/dot_product 等共享设施，被多个算子复用。
依赖方向：算子内核 → common 工具 → cpu_backend_internal 解析层 → CpuBackend/CpuWorkspaceArena 对外 API；能力与布局常量跨层可见但不可变。
