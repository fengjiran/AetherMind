- 每个被测组件以独立 `test_*.cpp` 文件承载一组相关 `TEST(...)` 用例，并通过 `using namespace aethermind;` 统一命名空间前缀。
- CPU 内核测试采用“候选实现 vs reference 实现”对比模式：调用被测内核与 reference 内核生成输出后，逐元素计算绝对误差并断言在容差范围内。
- 需要特定硬件能力的测试通过 `cpu::DetectCpuCapabilities()` 检测 `CpuFeature`（如 kAvx2、kFma、kFma）并在运行时跳过或条件编译，避免在无对应 ISA 的环境失败。
- 对后端行为进行策略化控制的测试通过构造 `CpuFeaturePolicy{.disabled_features = ...}` 禁用部分特性，以验证内核选择器回退到 reference 实现的分支。
- 权重打包相关测试先调用 `GetPackingRecipe` 获取配方，再用 `PackWeights` 配合 `test::TestCpuAllocator()` 分配内存，最后断言 `recipe()` 与 `storage().nbytes()` 符合预期。
