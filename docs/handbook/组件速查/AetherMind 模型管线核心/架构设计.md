本模块按职责拆分为三层：`formats/hf/`（hf_format_readers）负责把 HF 目录解析为 RawWeightTable；`weight/`（weight_management）在此基础上做 FP32 归一化、存储摘要、逻辑绑定与打包请求构建；最外层 `model_loader.cpp`、`loaded_model.cpp`、`build_model_graph.cpp` 等（model_pipeline_core）串联二者并输出后端的 ModelGraph/LoadedModel。
- 数据流单向：HF 目录 → hf_directory_reader/hf_json_reader/hf_safetensors_file → weight_binding_resolver/packed_weight_collection → loaded_model → model_loader::load。
- 共享边界由顶层头文件暴露：`raw_weight.h`、`resolved_model_weights.h`、`model_architecture.h`、`model_validation_options.h`、`rope_params_builder.h` 被所有子模块共同依赖，形成跨子模块的契约层。
- 架构类型（如 llama-dense）通过 `llama_dense_graph_builder` 与 `transformer_graph_common` 在加载阶段生成图，与具体后端解耦。
