模块由头文件 `runtime.h`、`runtime_builder.h`、`runtime_options.h`、`workspace_planner.h` 与对应实现组成，内部职责清晰分层：
- 配置层：`RuntimeOptions` 聚合 `AllocatorRuntimeOptions` / `BackendRuntimeOptions` / `ExecutionRuntimeOptions` / `WorkspaceRuntimeOptions` / `TracingRuntimeOptions` / `KVCacheRuntimeOptions` 六个子结构，作为所有装配阶段的单一输入。
- 装配层：`RuntimeBuilder` 维护 `pending_custom_allocator_providers_` 与 `pending_backend_factories_` 两个待注入列表，通过 `BuildAllocatorRegistry()` / `BuildBackendRegistry()` / `TryBuildKVCacheManager()` 依次构建 AllocatorRegistry、BackendRegistry 和 KVCacheManager，最终构造私有构造函数暴露的 `Runtime`；`Build()` 走 abort 路径，`TryBuild()` 走 StatusOr 可恢复路径，支持在注册阶段回滚 pending 列表。
- 运行期对象：`Runtime` 持有 AllocatorRegistry、BackendRegistry、KVCacheManager 与 workspace_limit_bytes，按设备类型懒创建并按需返回后端与分配器，对外不暴露构造，仅友元 RuntimeBuilder 可构造。
- 工作区规划层：`workspace_planner.h` 定义 `WorkspaceRequirement` / `WorkspaceBinding` / `WorkspacePlanLayout`，`PlanWorkspaceRequirements()` 对一维需求序列做一次性偏移计算与对齐校验，产出无内存分配的布局摘要，供 WorkspaceArena 分配统一缓冲后切片使用。
依赖方向单向向外：本模块依赖 backend/allocator/kv_cache/base/workspace_types，不被同层其他模块反向依赖。
