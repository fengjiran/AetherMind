- 所有可能溢出或越界的索引/步长计算统一走 `*Validated` 后缀辅助函数并返回 `StatusOr<size_t>`，不在调用处散落地做范围检查。
- 对外暴露的纯计算 API（如 `Offset`、`BytesPerPlane`、`TotalBytes`、`ValidateReservation`）采用 nothrow 风格并返回 `StatusOr`，将资源耗尽与逻辑错误区分开。
- 可移动但不可拷贝的所有者类型（如 `KVCacheManager`、`KVCacheStorage`）显式删除拷贝构造/赋值，并在移动后仍保持语义不变以满足无抛移动断言。
- 会话可见性通过 `generation` 版本号与 `Lifecycle` 枚举联合表达，视图在构造时捕获 generation 并在访问前校验，避免使用裸指针合法性判断。
