本模块由一组自包含的 CMake 契约（contract）组成，每个契约对应一个独立子目录：
- `test_build_contract.cmake` 是入口脚本，根据 `AETHERMIND_CONTRACT_CASE` 分发到 `alignment`、`std`、`fmt`、`existing-std`、`existing-fmt` 等场景；它调用 `execute_process` 以超时方式运行 CMake configure/build，并把输出写入 `<case_dir>/<name>.log`。
- `alignment_contract_project/` 直接 include `cmake/AetherMindBuildChecks.cmake` 并调用 `aethermind_validate_alloc_alignment`，用合法的 1/8/64/4096/$SIZE_MAX 以及非法的空串、负数、非幂次、溢出值等参数驱动边界回归。
- `build_contract_project/` 通过 `add_subdirectory` 引入主仓库，导出 `AetherMind` 目标到 `AetherMindContractTargets.cmake`，并链接 `spdlog::spdlog` 以校验格式后端选择；`build_contract_consumer/` 则作为外部消费者通过 `find_package` 风格导入该目标，同时编译 C++ 与 C API 契约对象库。
- `python_discovery_project/CMakeLists.txt` 直接 include `cmake/AetherMindFindPython.cmake`，通过 `notfound/disabled/disabled-required/valid-pin/invalid-pin` 五个 case 与 `missing/recovered` 两个 stage 组合，覆盖 FindPython3 的 NOTFOUND 缓存恢复、禁用开关、REQUIRED 拒绝与显式 pin 路径校验。
- `test_ctest_skip_policy.cmake` 动态生成 `CTestTestfile.cmake`，借助 `AetherMindTests.cmake::aethermind_set_discovered_test_properties` 对必需/可选 GTEST_SKIP 行为的 CTest 表现进行断言。
- `test_test_classification.cmake` 使用 `aethermind_test_labels` 断言数百个测试用例在 `interposer/model/cli/numerical/validation/isa-avx2/isa-policy/context-boundary/long-context/smoke/lifecycle` 等标签上的归属。
- `test_avx2_host_probe.cpp` 与 `test_required_execution_probe.cpp` 是供上述契约调用的原生探针可执行文件。
依赖方向单向指向 `cmake/*.cmake` 中的实现脚本；所有子项目均要求 `cmake_minimum_required(VERSION 3.28)`，且禁止在契约中自动下载依赖（例如强制存在本地 spdlog checkout）。
